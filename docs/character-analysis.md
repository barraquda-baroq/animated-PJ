# 『キミの右手のアイロニー』人物特徴の分析（本文からの抽出）

キャラクターデザインのために、本文（6,888行）を8区間に分けて精読し、外見を決める手がかりを拾い出した記録です。

- L123 は本文テキストの行番号です。
- 「強い推測」「弱い推測」は本文に直接は書かれていない読み取りです。
- 項目は分類ごとに、本文の順に並べています。

**作者確定で上書きした点（この記録より優先）**
- 主人公の目は細くない。第1話の「自分の細い目」（L115）は、訝しげに目を細めた場面。下の記録で「細目・切れ長」と読んでいる項目は採用していません。
- 主人公は陰キャ寄りだが、割とイケメンの部類。
- 叔母の手・腕に傷はない（左右とも）。「傷痕のない右手」（L6884）は、右腕に傷のある先輩との対比。
