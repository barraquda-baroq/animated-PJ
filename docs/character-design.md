# 『キミの右手のアイロニー』キャラクターデザイン設定書

PVアニメ用・主要3名の外見設定（最終版）

**3行でいうと**
- **主人公**：古い物を着潰す、骨格で格好いい少年。目は普通に開いた、切れのある目。陰は前髪の影・姿勢・座る場所で出す。
- **先輩**：骨格と姿勢で美人な、ピアニストの手を持つ人。右腕を隠す長袖の時期を経て、最終話の朝に、事故後初めて半袖になる（L6772）。
- **叔母**：首筋と手の綺麗な、30代後半の魅力ある大人の女性。甥と同じ目と髪で血縁を見せる【設計】。外では結い髪、家では下ろし髪と素顔。外の薄いアイラインで甥と同じ目を少し隠す案は【設計・要確認】（7.4の23）。手にも腕にも、傷は一つもない【確定】。

**この設定書の使い方**
- 印の意味
  - 【確定】作者が決めたこと
  - L123　本文の行番号
  - 【設計】本文にない、デザイン上の決定
  - 【要確認】第7章で作者に選んでもらう項目
- 本文の外見描写はごく少ない。ここに書いたことの大半は【設計】で、第7章の選択で差し替えられる。
- **PV制作スレッドに渡すとき**は、参考にした作品の名前（作品名・監督名・作家名・スタジオ名）を出さず、**第1章（画風ルール）と第6章（プロンプト）**を渡す。第1章と第6章には、こうした名前を一切書いていない。
- キャラの説明が要るときは、第3〜5章の「顔」「髪」「体と手」「衣装」までを渡す。第2章の血縁と結末の感情の話は、渡さなくてよい。
- 画像は「顔のアップ → バストアップ → 全身 → シーン」の順に固める（第6章の手順）。
- 絵を画像生成AIではなくコードで描く場合、第6章の英語プロンプトはそのまま使えない。第1章の比率と描き方、第3〜5章の数値（身長・頭身・瞼のかかり方・HEX）が実装の基準になる。

## 1. 画風の共通ルール

**目標**
- 劇場版の恋愛アニメの空気感と、骨格のある「ややリアル」な顔。
- 私服のシルエットと硬い影で人物を語る描き方。
- デフォルメの強い萌え顔にはしない。

**配分の目安**
- 骨格・影・衣装の考え方を6〜7割。
- 光と空気の繊細さ（窓の逆光、埃、肌の色トレス）を3〜4割。

**判断の物差し**
- 顔を記号ではなく、骨のある人の顔として描いているか。
- 一番効くのは、目の大きさ、鼻と唇の存在感、顎の骨格の三つ。

### 1.1 頭身・体格
- 描く：高校生は7〜7.5頭身、叔母は7.5頭身前後。頭は肩幅に対して小さめ。肩・腰・膝の位置は実際の人体どおり。
- 3人の目安
  - 主人公　178cm・7.5頭身
  - 先輩　160cm・7.2頭身
  - 叔母　165cm・7.6頭身
- 避ける：5〜6.5頭身の頭でっかち。子どものような短い胴と手足。脚だけ長いファッション画。全員同じ体型。

### 1.2 目（いちばん大事）
- 描く：アーモンド形。目は頭の縦の中央あたり、両目の間はほぼ目一つ分。
- 虹彩は小さめで、瞳孔を描く。ハイライトは小さな1点か、なし。瞳は焦げ茶〜黒の自然色。
- 睫毛は一本ずつ描かず、上瞼の線の太さに含める。二重は細い一本線。下瞼は目尻側の短い線か、省略。
- 上瞼が虹彩の上をどれだけ隠すかを、キャラごとに決める。
  - 主人公　上1/5
  - 先輩　上1/4（奥二重寄り）
  - 叔母　上1/4
- **主人公は細目にしない【確定】**。「切れのある目」であって「細い目」ではない。本文の「目が細くなる」（L62, L370）と、第1話の「自分の細い目に、力が入り」（L115。作者確定で、訝しげに目を細めた場面）は、しかめる・見据える・眩しがる表情。
- 上瞼の線は太めに引いても、瞼の肉は厚くしない。眠たげな半眼は誰にも使わない。
- 避ける
  - 大きな丸い目、虹彩が丸ごと見える目。
  - 複数のハイライト、星やハートの光、キラキラの虹彩。
  - 顔の中心より下に置いた目。跳ね上がる睫毛。
  - 糸目、細目、眠たげな厚い瞼。

### 1.3 眉
- 描く：厚みのある眉を、眉骨に沿って目の近くに置く。数ミリの角度で感情を出す。
- 前髪は眉で止めるか、前髪越しに眉が透けて見える長さにする。
- 避ける：額の高い位置に浮く、細い弧だけの眉。前髪で常に隠れる眉。

### 1.4 鼻
- 描く：斜め向きは、鼻筋の線・鼻先・小鼻と、その影。正面でも鼻先の影を残す。横顔で高さと形を描き分ける。
  - 主人公　直線の鼻筋に、鼻根の少し下の小さな骨の段。
  - 先輩　細く通った鼻筋に、小さく締まった鼻先。
  - 叔母　主人公と同じ直線の鼻筋で、少し長い。
- 避ける：点の鼻、鼻のない顔、三角の記号、全員同じ鼻。

### 1.5 口
- 描く：口幅は左右の瞳孔の間くらい。上唇の線と、下唇の下の影で立体を出す。
- 休んでいる時の口角は、3人とも水平。への字を初期値にしない。
- 女性の唇は、彩度を落とした控えめな色。
- 避ける：極小の口、ω口、猫口、顔の半分を占める三角の口、グロスの光沢、強い口紅。

### 1.6 輪郭・首・肩
- 描く：頬骨、エラから顎への角、幅のある顎先。横顔に額・眉骨・鼻・唇・顎の凹凸を出す。耳は眉と鼻の下端の間。
- 首は長く、腱を細い線で示す。主人公は喉仏。鎖骨と肩の傾きを描く。
- 姿勢で性格を出す。
  - 主人公　少し猫背で、ポケットに手。
  - 先輩　伸びた背筋と、力の抜けた肩。
  - 叔母　疲れても崩れない立ち姿。
- 避ける：丸い赤ちゃん頬、針のようなV字顎、平らな横顔、棒のような首、全員のモデル立ち。

### 1.7 髪
- 描く：大きな塊を数個。重さと重力。毛束の線は最小限。色は黒〜焦げ茶の自然色。
- ハイライトは無しか、硬い縁の帯を一本だけ（地の色より少し明るい程度）。
- 主人公と叔母は、同じ焦げ茶黒で、柔らかいゆるいうねり。先輩だけが重い直毛の黒。
- 避ける：アホ毛、触覚、トゲトゲの房。青・紫・ピンク・パステルの髪色。天使の輪の光沢。無数の細い毛束。重力に逆らう髪。

### 1.8 手（音楽の物語なので最重要）
- 描く：指の長さ、関節の節、甲の腱、短い爪。掌の長さは顎から生え際くらい。
- ギターの左手は、指先を立てて弦を押さえる。右手は手首を脱力させてストローク。
- ピアノは、指のアーチ、手首の高さ、打鍵の重さ。
- 手の芝居（握る、こわばる、触れる直前で止まる）で感情を語る。
- 避ける：ミトンやボールのような手、ソーセージ指、骨のない細すぎる指、指の本数の崩れ、楽器に正しく触れていない手。

### 1.9 線
- 描く：細め〜中くらいの線に、入り抜きの強弱。外形線はやや太く、内側は細く。
- 鼻・唇・瞼など肌の内側の線と、影の境界は、茶系の色トレス。
- 避ける：均一な太い主線、ステッカーのような縁取り、汚いラフ線、線のない厚塗り。

### 1.10 影と光
- 描く：影は1段、深い所だけ2段目。縁はくっきり硬く、形は光源から設計する（顔の半分を闇に沈める、窓枠の影が体を横切る）。
- 影の色は環境光の色にする。夕暮れは青紫、白熱灯は琥珀、蛍光灯は緑がかったグレー。夜はコントラストを強く。
- 光は画面の中で説明できるものにする。窓の逆光、埃に滲む光、街灯、白熱灯、アンプの赤いランプ。薄いフィルムグレイン。
- 避ける：エアブラシのグラデーション、光沢の多段影、頬のぼかし、全カットのリムライト、全面のブルーム、レンズフレア、キラキラの粒。

### 1.11 色
- 描く：彩度を落とした中〜低明度。シーンごとに色温度をそろえる。肌は黄土を含んだ暖かいベージュ。
- 白は生成りか、ごく薄く色を含んだ白。黒は茶か青を含んだ黒。
- キャラごとのアクセント色は一つ（主人公＝錆、先輩＝赤、叔母＝ワイン）。
- 避ける：パステル、ネオン、高彩度、真っ白な肌、真っ黒な影、強いティール＆オレンジ。

### 1.12 衣装
- 描く：服のシルエットで人物を語る。肩の落ち方、丈、生地の重さ、着古し。皺は関節と重力に従う少数の線。
- 現代日本の実在の服。制服は着方の癖で個性を出す。
- 避ける：コスプレ的な衣装、フリル、髪飾りのリボン、アクセサリーの盛りすぎ、ロゴ、プリント文字。

### 1.13 表情と芝居
- 描く：振れ幅は小さく。瞼の落ち方、眉の数ミリ、口角の非対称、視線の外し方で語る。笑顔は短く、左右非対称。
- 涙は下瞼に溜まる一筋程度。
- 赤面は、ぼかしや斜線でなく、肌色を一段赤くした面で描く。
- 動きは重心と体重を持たせ、止めの「間」を恐れない。横顔のアップ、引きの構図、望遠の圧縮。
- 避ける：満面の笑み、大口のリアクション、汗・怒りマーク・頬の斜線などの漫符、白目化、滝の涙、ピースや首かしげ。

### 1.14 年齢の描き分け
- 髪型だけでなく、目の形・鼻・顎・首の太さで顔を描き分ける。
- 高校生は頬の肉がわずかに残るが、骨格ははっきり。
- 叔母は30代後半の情報（目の下の細い線、頬骨の下のわずかなこけ、口元の短い線、首の質感）を、描き込みすぎずに入れる。
- 避ける：同じ顔に髪型だけ変えた量産顔。叔母が生徒と同年代に見えること。皺だらけの老け顔。

### 1.15 style.json からの変更点
- 目：「細い切れ長・厚い上瞼」を、「普通に開いた、切れのある目」に改めた（主人公の確定事項）。瞼のかかり方はキャラ別（1.2）。
- 汎用ポジティブ文：主人公の確定事項に反する目の語を含むので、そのまま使わない（第6章で差し替え）。
- 汎用ネガティブ：「ribbons」（先輩の襟のリボンが消える）と「same face」（同じ人物を出し続ける運用と衝突）を外した。

## 2. 3人の並べ方

### 2.1 影だけで分かる3つの形（T・A・I）
本作の山場は、顔が見えない場面が多い。
- カーテンの切れ目に立つ先輩（L1413）
- 逆光の喫茶店の主人公（L3172）
- 雷の逆光の先輩（L4180）
- 戸口に立つ叔母の影（L615）

顔が潰れても形だけで誰か分かるように、シルエットを先に決める【設計】。

**主人公＝T**
- 腰で切れる、箱型の肩の革ジャン。まっすぐな2本の脚。
- 右肩から斜めに突き出る、ギグバッグのネック。
- 少し前に出た頭（軽い猫背）。外形が少し不揃いな髪。

**先輩＝A**
- 背中の中ほどまで落ちる、黒髪の縦の帯。動くと揺れ（L1882「揺れる長い髪」）、一拍遅れてついてくる【設計】。
- 華奢な肩、膝丈の裾の広がり、垂直に伸びた背。

**叔母＝I**
- 外では、高くまとめた頭と、見えているうなじ。ふくらはぎ丈の直線のコート。
- 家では、ふくらはぎ丈のロングカーディガンで、縦の一本線を保つ。
- 振り向かない後ろ姿。

**取り違えの検証**
- 3人を逆光の黒ベタで並べ、形だけで見分けられること（第6章 6.7）。

**引きの画での「1秒の目印」**
- 主人公：ギグバッグのネックの斜線。バイクでは生成りのヘルメットの白い点。冬は錆色のマフラーの帯。
- 先輩：明るい服の上の、唯一の黒（長い髪の帯）。事故前は赤いリボンの点。事故後は「右側だけ白い体」（24〜27話のギプス、36話以降の手首の包帯）。29〜34話の装具は濃紺（4.6、6.5）なので、白ではなく、吊った右腕の形と右頬にかかる髪で見せる。
- 叔母：縦一本の裾と、高い位置のまとめ髪。

### 2.2 明るさと色の持ち主
明るさの段は **先輩（明）→ 主人公（中）→ 叔母（暗）**。主人公は、恋人と母親代わりの間の明るさに立つ。

| 人物 | 色の系統 | アクセント（一つ） |
|---|---|---|
| 主人公 | 暖色：茶芯の黒、擦れた茶 | 錆テラコッタ |
| 先輩 | 寒色：濃紺、青灰、青みの白 | 赤（3年のリボン、リンゴ） |
| 叔母 | 暗色：チャコール | ワイン |

- 独占ルール：錆は主人公だけ、紺と青灰は先輩だけ、ワインは叔母だけが着る。
- 共有してよい中立色：制服のグレー、シャツの白、デニムのインディゴ。
- 脇役には3人の持ち色を着せない。先輩の母は、灰ベージュ #9C948A の「色のない人」。
- 叔母のワインは、先輩の赤を暗く沈めた同系色【設計・要確認】。二人が彼に向けた感情が同じ系統だったことを、台詞にせず色で埋めておく（結末の「区別」L6872-6875）。

**白の温度【設計】**
- 先輩の白は、青みのある白。白い家（L1583）、ギプス、病室、白い橋、「真っ白な世界」（L188）。
- 主人公の白は、黄ばんだ生成り。母の形見の白いギター（L3031）とヘルメット。小さな面積で、画面で一番明るい物にする。
- 最終話の朝、先輩の半袖Tを生成りにして、二つの白の温度をそろえる。

**光での変化**
- 白熱灯の下では、主人公の琥珀に透ける瞳と、叔母のワインが近づく【設計・要確認】。血縁と感情を色で語る解釈なので、7.1の3でワインを使わない場合は、この項ごと外す。

### 2.3 血縁の面影

#### 主人公 ⇄ 叔母（⇄ 亡き母）
本文に、二人の顔の相似は書かれていない。L5164「姉さんにそっくり」は、性格（一度決めたら譲らないところ）についての台詞。外見の相似は【設計】として、「同じ家の顔」に作る。

| 共有するもの | 中身 |
|---|---|
| 目の型 | 目頭が鋭く切れ込むアーモンド形、細い平行二重 |
| 瞳の色 | 暖かい焦げ茶 #5B3C27。光で琥珀に透ける |
| 眉 | 厚みのある真っ直ぐな眉 |
| 横顔 | まっすぐな額、鼻根の浅いくぼみ、直線の鼻筋 |
| 髪 | 焦げ茶黒、柔らかいゆるいうねり、左分け、襟足の外ハネ |
| 口 | 休止時は水平。「表情のない顔」の元 |
| 癖 | 目を伏せる角度と速さ（主人公 L5023, L4243／叔母 L656, L5156） |
| 後ろ姿 | 背中越しに言い残す（主人公 L733-735／叔母 L630-631）。同じ構図で撮る |

違えるもの
- 身長と顎の角。主人公の知らない、父の側として残す。
- 叔母は細面で、鼻が少し長い。
- 叔母は外では、ごく薄いアイラインで目尻をわずかに持ち上げ、甥と同じ目を少しだけ隠している【設計・要確認】。
- 素顔に近い時（33話、エピローグ）に、甥と一番似て見えるようにする。

亡き母（叔母の姉）を回想で出す場合【要確認】
- 同じ目と同じ髪の、長い髪の若い女性。
- 服は主人公と同じ暖色系。

#### 先輩 ⇄ 先輩の母
本文：母は「端正な顔立ち。どこか先輩に似た雰囲気」（L3948）、「どことなく似た印象」（L1612）。先輩は姿見に母を見る（L5726）。

| 共有するもの | 中身 |
|---|---|
| 骨格 | 細く通った鼻筋、薄い上唇、細いが骨の通った顎線、わずかに上がる目尻 |
| 眉間の皺（縦2本は【設計】） | 母は常に（L4266）。先輩は張り詰めた時だけ（L483, L699） |
| 色 | ほぼ黒の瞳と黒髪 |
| 腕を掴む型 | 母は組んだ腕で二の腕を掴む（L4284）。先輩は左手で右肩・右腕を掴む（L4625, L6817） |

母だけの記号（先輩にも叔母にも与えない）
- 細いフレームの眼鏡（L1612, L5721）。先輩は掛けない（L5724）。
- いつも低くきついシニヨン【設計】。
- 灰ベージュの服【設計】。

演出の約束
- コンクールのまとめ髪（L3222「髪をアップに纏めて」。母と同じ低いシニヨンにするのは【設計】）は、母と同じ形にする。先輩が一番母に似る瞬間。
- 32話の引きこもりの姿（乱れた髪、素顔、こけた頬）は、39話の母（L6474「整っていない髪。化粧っ気のない顔」）と同じ形で描く。
- 姿見の場面（L5721-5726）は、先輩の顔に眼鏡の縁の鈍い反射を足すだけで母に見えるかを、検証項目にする。
- 39話、先輩が壁にもたれて腕を組む（L6514）。28話の母の構図（L4266）の反転。動かない右腕は、左腕で右前腕を抱えるように組む。
- 腕組みと腕を掴む仕草は、先輩にも本文どおり使う。母と分けるのは、眼鏡と、低いシニヨンと眉間の皺が「常態」であること。
- 妹ミカは、横顔だけ先輩に寄せる（L3835）。髪は肩までの一つ結び【設計】。

### 2.4 手と腕の三角形

## 3. 主人公

### 3.1 一言コンセプト
**古い物を使い込む少年【設計】。弾くのは、顔も知らない母の形見の白いギター（L281, L5110）。**
教室では日陰の席にいて、ギターを構えると大人になり、笑うと子供に戻る。顔は整っているのに、光の当たる側には座らない。

### 3.2 基本データ
- 年齢：高校2年（L70「一年からの悪友」からの推定）。4月生まれ（誕生日は臨海公園へ出かける日 L6118、その日は「四月の風」L6174）。第1話の4月中に17歳になる。37話で「来週、十八歳になる」（L6069）。34話（2月）で中退を決め（L5211）、35話で、春休みの前に退学届を出したと語られる（L5444）。
- 身長：178cm【設計】
  - 「もう十分大きいよね」（L1065）
  - 抱きとめた先輩の頭が肩口に来る（L3140）
  - ヒールの先輩の顔が胸に埋まる（L3555）
- 体重：62kg。37話以降は57kg【設計】（L5956「少し痩せた？」、L5985「別人みたい」）。
- 体格：細身で手足が長い。肩幅だけ先に大人になりかけている。胸は薄いが、腕は力強い（L6702）。
- 頭身：7.5。
- 利き手：右（果物ナイフ L3806、ピックとストローク L2198）。ギターは右利き用で、左手で押弦（L4177）。

### 3.3 顔
**方針**
- 格好良さは、骨格と開いた目で出す。
- 陰は、前髪の影・姿勢・座る場所・芝居で出す。
- 顔の部品（への字口、常時の隈、伏し目）で陰を作らない。
- 「割とイケメンの部類」【確定】は、正面の設定画でも分かるようにする。

**部位**
- 輪郭：やや面長の卵形。エラから顎に角があり、顎先に幅がある。17歳らしい頬の肉をわずかに残す。細い線一本の喉仏。
- 目
  - 中くらいのアーモンド形で、**普通に開いた目**【確定】。上瞼は虹彩の上1/5だけを隠す。
  - 目頭は鋭く切れ込む。目尻はほぼ水平（下がっても2°程度）【要確認】。
  - 細い一本線の平行二重。睫毛は上瞼の線の太さで表し、長く描かない。
  - 瞳は暖かい焦げ茶 #5B3C27。逆光やアンプの灯で琥珀 #9A6B3C に透ける（叔母と同じ）。ハイライトは小さく1点。
  - 目を細めるのは、しかめる（L62）、見据える（L115）、眩しがる（L370）時と、本気で笑う時（L791。下瞼が上がって細まる形は【設計】）だけの表情差分。
- 眉：厚みのある真っ直ぐな眉を、目のすぐ上に低く置く。前髪越しに透ける。
- 鼻：直線の鼻筋に、鼻根の少し下の小さな骨の段。鼻先は小さく締まる。
- 口：口幅は瞳孔の間。上唇は薄く、下唇がやや厚い。休止時の口角は**水平**。
- 耳：標準の大きさ。上半分は髪に隠れる。ピアスなし。
- 肌：黄土を含む暖かいベージュ #E2C3A6。夜型で、やや色白。
- 隈：通常は描かない。35〜38話の憔悴期と、深夜の場面だけ。
- ほくろ：なし。

**格好良さを出す所**
- 骨格：鼻筋、顎の角、喉仏、長い首。
- 開いた二重の目と、低く厚い眉の組み合わせ。
- 身長と手足の長さ、大きな手。
- 横顔。先輩が見惚れるのは、いつも横顔（L374, L825, L2791）。
- ギターを構えると背筋が立ち、顎が引かれる（L495「急に大人びて見えた」）。

**陰を出す所**
- 前髪が眉に落とす影。座るのは陽の当たらない席（音楽室 L311、中庭のベンチで顔に木の陰 L332）。
- 軽い猫背と、少し前に出た首。
- 視線だけを動かす芝居（L85）。有線イヤホンで周りを閉じる（L74）。
- 「冷めてる」（L79）は、顔立ちではなく、配置と態度で出す。

**陰が外れる瞬間**
- 笑うと下瞼が持ち上がって目が細まり、子供の顔になる（L791）。
- 雨で前髪が額に張り付く。演奏中、汗で前髪が割れる。
- 最終話、シャワーの後（L6610）に濡れ髪を掻き上げ、物語で初めて額と眉が全部見える【設計】。

### 3.4 髪
- 長さ：前髪は眉にかかる（眉は透けて見える）。サイドは耳の上半分を覆う。襟足はシャツの襟に触れる。「切りに行くのを2か月忘れた」くらい。
- 色：焦げ茶黒 #2B211B。地毛で、染めない。逆光で赤茶に透ける。ハイライトは硬い帯一本（#5A4234）まで。
- 質感：柔らかい髪に、ゆるいうねり（叔母と同じ）。整髪料なし。
- 分け目：左分け。前髪は右目側に重く落ち、左の額が少し開く。先輩がいつもいる左側に、顔が少し開いている【設計】。
- つむじ：頭頂のやや右後ろ。
- 襟足：外へ跳ねる癖（叔母と同じ家の癖）【設計】。
- シルエット：頭頂は平らめ。耳の後ろと襟足が少し外へ跳ねる。毛束は少なく、トゲにしない。

**状態差分**
- 雨：濡れて束になり、額に張り付く【設計】（6話の夜の雨 L1020、27話の嵐 L4076）。
- ヘルメットを脱いだ後：頭頂が潰れ、手櫛で掻き上げる。
- 演奏中：前に落ちる。汗で割れて目が出る。上を向くと額が出る（L2387）。
- 文化祭1日目：目の周りに、油性ペンの丸い隈が残る（L1797）。
- 35〜38話：切らずに伸び、耳が隠れ、襟足が首にかかる。
- 最終話：寝癖【設計】（L6598 は深夜3時過ぎに寝て、暑さで8時に起きる場面）。シャワー（L6610）の後に、濡れ髪を後ろへ掻き上げる【設計】。

### 3.5 体と手
**姿勢**
- 普段：軽い猫背で、首が少し前。片脚に重心。手は革ジャンのポケット。
- 中庭のベンチ：パックジュースを咥え、イヤホンをして目を閉じ、少し宙を見る角度で体を緩やかに揺らす（L332, L334）。深く沈んで脚を投げ出す座り方は【設計】。
- 構えた時：背骨が立ち、顎を引く（L495）。
- 座奏：スツールに座り、右足でテンポを取る（L1674, L6616）。クラシックギター出身（L5113）の座り方が残っている。

**手**
- 全体：掌が大きく、指が長く、関節が太い。甲の腱が浮く。
- 左手（押弦）：人差し指〜小指の指先が平たく硬い。黄味を帯び、弦の溝の跡が残る（L800, L6796）。爪は深爪寸前。
- 右手（ピック）：手首は脱力。爪をわずかに残して、ヤスリで整える（クラシック出身の名残）【設計】。
- 冬の手：ファミレスのバイト（L640）で、指の関節が赤く荒れる【設計】。先輩にハンドクリームを贈る（L2661）のに、自分は塗らない。

**左手親指の傷痕（27話以降のみ）**
- 位置：親指の付け根（L4147, L4161）。縫合される（L4220）。手の甲側から母指球側へ、斜めに約4cm、両側に縫い跡の点【設計】。
- 経過
  - 28話　白い包帯（L4220）
  - 29〜34話　赤い線【設計】（傷痕が残っていることは L4496。色は本文にない）

- 握り：親指をネックの上から出す握りが癖【設計・要確認】。演奏カットで、傷が自然に映る。
- 右手には描かない。27話より前に描かない。

**憔悴期（37〜38話）**
- 首、鎖骨、手首の骨が浮く。同じ革ジャンの肩が落ちて余る。

### 5.3 顔
**方針**
- 甥と「同じ家の顔」。違いは、細面、少し長い鼻、外での薄い化粧と結い髪だけ。
- 「母」だけの顔にせず、首筋や手の綺麗な大人の女性として描く。性的な記号は使わない。

**部位**
- 輪郭：細面の卵形。頬骨が出て、その下がわずかにこける。顎は細いが、はっきりした線。首との境に、年齢の柔らかさ。
- 目：主人公と同じ型。目頭が鋭く切れ込むアーモンド形、細い平行二重。
  - 上瞼は虹彩の上1/4を隠す（甥より、少しだけ落ち着いた目）。静かに据わった、探る視線（L622, L639）。
  - 瞳は甥と同じ #5B3C27。光で琥珀に透ける。ハイライトは極小。
  - 外では、ごく薄い焦げ茶のアイラインで、目尻をわずかに持ち上げる。跳ね上げにはしない【設計】。
  - 家でほぼ素顔の時は、目尻が甥と同じほぼ水平に戻る。
- 目の弧（芝居の中心）
  1. 普段は、静かに据わった目。
  2. 「母さん」と呼ばれて全開になり、穴が空くほど見つめる（L5131, L5133）。この一瞬だけ、甥とまったく同じ目。
  3. エピローグで、静かに閉じる（L6884）。
- 眉：甥と同じ、厚みのある真っ直ぐな眉。眉尻だけ少し上げて整える。何かに気付くと、少しだけ上がる（L644）。
- 鼻：甥と同じ直線の鼻筋で、少し長い。

## 6. 画像生成プロンプト（英語）

### 6.1 使い方
**書かない語**
- 作品名・監督名・作家名・スタジオ名は、プロンプトにも会話にも書かない。外れた時は名前を足さず、外れた部位（目・鼻・顎・影・色）の語を強める。
- 実在の楽器ブランドや型番、車種名も書かない。形で書く。
- 量産顔に流れる語は、ポジティブには使わない（6.3 のようにネガティブに入れるのはよい）：anime, anime girl, beautiful, pretty, cute, handsome, bishounen, masterpiece, best quality。
- 年齢は boy／girl と書かず、young man／young woman と age-accurate で書く。

**組み立て順**（前ほど効く）
1. 共通スタイル文（6.2）
2. キャラの外見固定文（6.4）
3. 衣装の差し込み文（6.5）
4. 時期の差し込み（年齢、傷、髪の状態）
5. 場面と光（6.8）

ネガティブは、共通ネガティブ（6.3）＋キャラ別ネガティブ（6.4）＋時期のネガティブ。

- 先頭ほど効き、長い文が途中で切れる生成器では、1（約135語）と設定画用の追加・体格の行が先に枠を使い、2の「Face:」行が後ろに回る（6.6 の完成形では約200語目から）。その場合は1を下の短縮版に替え、2は年齢と性別の句（例 `a seventeen-year-old Japanese young man`）のすぐ後に「Face:」行を置き、体格・Hair・Hands をその後に回す。削るのは5と衣装の細部から。
```
hand-drawn 2D cel animation film still, grounded realistic proportions, clearly drawn nose and defined jawline, fine tapered ink linework, two-tone hard-edged cel shading, muted low-chroma palette, subtle film grain
```

**作る順番**
1. キャラごとに、正面・斜め・横顔の設定画を確定させる（6.6）。
2. それを参照画像として毎回渡す。シードを固定する。可能なら、確定した設定画で軽い追加学習をする。
3. 顔のアップ → バストアップ → 全身 → シーンの順に進む。
- 二人以上の場面は、キャラごとの参照画像を使うか、一人ずつ作って合成する（顔が混ざるのを防ぐ）。
- アニメ特化の生成モードは、萌えに寄りやすい。汎用モデルは逆に、写実のイラストや写真に流れやすい。汎用モデルを使う時は、共通ネガティブの `semi-realistic painting, photorealistic, photograph, 3D render` を外さず、写実に寄ったら `hand-drawn 2D cel animation` と、線と2段の影の語を前に出す。
- 自動の美化は、切らずに弱める程度にする。完全に切ると、主人公と先輩が「普通の顔」に落ちやすい（作者確定：主人公は割とイケメン、先輩は美人）。
- 手と楽器は崩れやすい。手のアップは別に作って差し替える。

**左右の検証**（毎回）
- 主人公の傷は、左手親指の付け根（27話以降だけ）。押弦は左手、ピックは右手。ギグバッグは右肩。
- 先輩の傷は、右腕だけ。耳に掛けるのは右側の髪。並びは、事故前と結末で主人公の左。
- 主人公と叔母の分け目は左。
- 全体が鏡像なら、画像ごと反転して戻してよい。部位ごとに左右が食い違う出力は不採用。
