# 小物と生活のライブラリ API — `pv/engine/lib/props.js`

『キミの右手のアイロニー』PV 用の小物アセット。すべて Canvas2D で描き、決定論的（`PV.rng` / `PV.noise2` を使い、`Math.random` は使わない）。
ctx の状態は各関数の中で `save()/restore()` 済み。
ショーケースは `pv/scenes/_dev_props.js`（`dev_props_1` 〜 `dev_props_15`、計測用 `dev_props_perf`）。美術監督の講評と修正の記録は `analysis/art_review/props_critique.md`。

> **最終版の要点（美術監督チェック後）**
> - うさぎリンゴは「横に寝かせて切り口の半月を見せ、耳が立つ」定番の姿に統一した（皿でも弁当の中でも同じ描画）。タコさんウインナーの目は頭の前面に見える。
> - 弁当の蓋の既定の位置は**箱の下に敷く**に変えた（`lidX/lidY` を指定すると横に置ける）。
> - イヤホンに平置きの `mode:'laid'` を追加した。ハンドクリームのギフト箱は全面的に作り直した（`tubeAt` / `tinAt` で配置を変えられる）。
> - 描画時間は**ラスタライズを強制して**測り直した数字（下の「性能」）。動く小物も、静的な部分はスプライトにキャッシュしてある。

---

## 共通オプション（全関数）

| オプション | 意味 | 既定 |
|---|---|---|
| `x, y` | アンカー位置（px、1920×1080 基準）。アンカーの意味は関数ごとに違う | 0,0 |
| `s` | スケール。1 = 各関数の「自然サイズ」 | 1 |
| `rot` | 画面内の回転（rad） | 0 |
| `alpha` | 全体の不透明度 | 1 |
| `tone` | 色彩設計キー（下表）。オブジェクト `{amb,k,sat,hi,sh,rim,rimA}` で自作もできる | `'day'` |
| `light` | **光源の方向**（物体から光源へ向かう画面上の角度, rad）。`-2.3`=左上, `Math.PI`=左の窓, `-0.45`=右上の窓, `-1.57`=真上 | `-2.3` |
| `rimA` | 光源側の縁に入るリムライトの強さ 0..1（逆光のショットでは上げる） | tone による |
| `shadow` | 机や地面への落ち影・接地影 | `true` |
| `ink` | 色トレス（細い色付きの輪郭線）の濃さ 0..1 | 0.8 |
| `lw` | 線幅の基準 px（画面上で 1.5px 前後になるよう自動で補正） | 1.5 |
| `cache` | `false` にすると毎フレームベクターで描く（スプライトキャッシュを使わない） | — |
| `cacheScale` | ズーム中にキャッシュの解像度を固定したいときの基準スケール（例: `s` が 1→1.6 に動くカットなら `cacheScale: 1.6`） | — |
| `res` | キャッシュ解像度の倍率（アップで甘いときは 1.5 など） | 1 |

### `tone` プリセット（スタイルガイドの色彩設計に対応）
| キー | 用途 |
|---|---|
| `day` | 中庭の青空・晴天（補正なし） |
| `warm` | 春の音楽室・午後の光（#fff3dc 系に寄せる） |
| `cool` | 病室の冷たい白、秋の高い青空 |
| `rain` | 雨の音楽室・雨の窓辺（青灰、低彩度） |
| `night` | 夜の臨海公園（紺＋琥珀のリム） |
| `sunset` | 夕景 |
| `mute` | 沈黙の日々（彩度を落としたベージュ灰） |
| `white` | コンクールの真っ白な世界 |

`PV.lib.propsTone(o)` を使うと、同じ色変換関数 `T.c('#hex')` をシーン側でも使える。夜は光源の向き（`light`）とリムの色を必ず決める（`dev_props_10` は右上の街灯を想定）。

### 性能（ウォームキャッシュ。1回の呼び出しごとに `getImageData` でラスタライズを強制して計測）
静的な小物は、初回フレームで解像度バケット（√2 刻み）ごとにスプライト化する。初回は 5〜260ms かかり、2回目以降は drawImage だけになる。

| 関数 | 1呼び出し | 備考 |
|---|---|---|
| bento（通常/焦げ/蓋＋箸） | 5.5〜6 ms | 2263px 幅のスプライトを drawImage するだけ |
| packJuice / apple / rabbitApple / applePie / appleCake / earplugs / key / handCream / fruitKnifeAndApple | 0.1〜0.3 ms | スプライト |
| phone | message 7 / lock 1.4 / player 1.8 / off 0.5 / 裏面 0.3 ms | 影と筐体（下層）、ガラスの艶（上層）はスプライト。画面だけ毎フレーム描く |
| ecgMonitor | 5.3 ms | 筐体、画面の地とグリッド、操作部はスプライト。波形と数値だけ毎フレーム描く |
| notebookName | 1.7 ms（全頁 s1.25: 7.7 ms） | 書き終えた画は差分でインク層にキャッシュする。にじみは縮小コピーで作る |
| courtyardBench | 12 ms | 木漏れ日の合成（毎フレーム） |
| umbrella | ビニール 9 / 紺 4 ms | |
| handkerchief | 吊り 9 / 折り 0.2 ms | 折りはスプライト |
| earphones | 吊り 1.2 / 平置き 0.3 ms | |
| necklace / ivDrip | 1〜3 ms | |

> 以前の報告（0.1〜18ms）は、ラスタライズさせずに測っていたので実際より軽く出ていた。修正前の実測では、スマホは 33〜56ms、心電図モニターは 44〜63ms あった。

## 1. `PV.lib.bento(ctx, o)` — お弁当
- **アンカー**: 箱の床の中心（テーブル面）。**自然サイズ**: 箱 560×380（約 19cm 相当で、食材は実寸比）。画面幅の半分程度なら `s≈1.2〜1.4`、アップで `s≈2`。
- **見た目**: 紺のプラ弁当箱（艶のある側面、縁のハイライト）。ご飯と梅干し、レタス、唐揚げ×2（ゴツゴツした衣と油のてかり）、クッキングシートのひだ、デミグラスの照りのハンバーグ、ブロッコリー、プチトマト、渦巻きの卵焼き×3、**ゴマの目のタコさんウインナー×2**、**うさぎリンゴ×2（横に寝かせて切り口の半月を見せ、耳が立つ）**。斜め上ビューには軽い遠近（台形）がつく。
- `o.view`: `'angle'`（斜め上から・既定）| `'top'`（ほぼ真上）| `'flat'`（真上）。`o.elev` で rad を直接指定できる。`o.persp` は遠近の強さ（angle で 0.13）。うさぎリンゴの縦の潰れは仰角から自動で決まる。
- `o.burnt: true` — 後半の「ちょっと失敗しちゃった」。卵の黄色を残したまま斑に焦げ、縁が焼けた卵焼き、歪で焦げたタコさん（目なし、足の長さが不揃い）、少し歪なおにぎり×2、プチトマト×2、ブロッコリー、皮付きリンゴ×2（うさぎにできていない）。片手で詰めたなりにぎっしり入っている。**箱は同じ紺**なので前半のカットと対比できる。
- `o.box`: `'navy'`（既定）| `'pink'` | `'wood'`
- `o.lid: true` で蓋を置く。**既定は箱の下に敷いた状態**（縁とロックの爪が箱の足元から覗く）。横に置くときは `o.lidX, o.lidY`（箱ローカル座標の位置。例: 右奥なら `400, -120`）と `o.lidRot`（度）を指定する。蓋には内側の浮き出た面、縁の段差、ロックの爪、二重の映り込みがある。
- `o.chopsticks: true` で手前に箸と箸箱を置く（落ち影つき）。`o.wash: false` で光をなじませるグラデーションを切る。
- 例: `L.bento(ctx, { x: 860, y: 640, s: 1.3, tone: 'warm', light: -2.62, lid: true, chopsticks: true })`

## 2. `PV.lib.packJuice(ctx, o)` — 紙パックのジュース
- **アンカー**: 底面の中心（机の上）。**自然サイズ**: 約 150×300（ストロー込みで高さ ≈ 410）。
- **見た目**: 200ml の紙パック。パッケージの絵は**葉つきのリンゴと、星形の芯が見える輪切り**。「りんご／APPLE 100%」、側面の成分表、上部の圧着ヒレ、折り込まれた耳。蛇腹ストローの先は**噛んで平たく潰れ、歯形**が残っている。
- `o.flavor`: `'apple'`（既定）| `'peach'`（割れ目、赤み、葉のある桃）| `'coffee'`（豆2粒）。`o.turn`（ヨー, 既定 0.55）、`o.elev`（0.32）
- `o.straw`（既定 true）、`o.bite`（歯形, 既定 true）、`o.strawLean`, `o.strawBend`（rad）、`o.dent` 0..1（両手で握ってできた低い位置の凹み。柔らかい影とその上の稜線）

## 3. `PV.lib.earphones(ctx, t, o)` — 有線イヤホン
### 3a. 吊り・装着（既定）: 二人で片方ずつ
- **座標系**: スクリーン座標を直接指定する（`x,y,s` は使わない）。
- `o.a`, `o.b`: `{x, y, ang}` 二人の耳のイヤーピースの位置（`ang` はケーブルが出る方向。既定は下 = π/2）
- `o.split {x,y}`: Y字の分岐（既定は二人の中点の 160px 下）。二本のケーブルが**二人の間で弧（カテナリー）**を描いて分岐に集まる。
- `o.end {x,y}`: 本線の行き先（ポケットやスマホ）。`o.plug: true` で 3.5mm プラグを描く（`o.plugAng`）。
- `o.sag`（たるみ px, 既定 40）、`o.sagMain`、`o.sway`（風の揺れ px, 既定 6。t で揺れる）、`o.color 'black'|'white'`（既定は少し高そうな黒）、`o.bud`（イヤホン本体の大きさ。1 ≈ 46px）、`o.lw`（ケーブルの太さ 3）、`o.budsVisible: false`（耳に隠れているとき）
- ケーブルには光源側のスペキュラ線と逆光のリムが入るので、空バックのシルエットでも暗い背景でも読める。

### 3b. `mode: 'laid'` — 机やベンチに置いたイヤホン（静止物なのでスプライト）
- **アンカー**: とぐろの中心。**自然サイズ**: 約 560×260（`k=0.55` のとき）。
- 横倒しの本体2つ（ハウジング、ノズル、ステム）、Y分岐へ集まる2本のリード線、ゆるくとぐろを巻いてプラグへ続く本線。交差は後から描く順で表現し、接地影もつける。
- `o.k`（面の奥行きの潰れ。ベンチの座面くらい浅いなら 0.3、机を斜め上からなら 0.55）、`o.seed`（巻き方）、`o.color`、`o.plug`（既定 true）、`o.lw`（4.2）、`x, y, s, rot`
- 例（中庭のベンチ）: `L.earphones(ctx, t, { mode: 'laid', x: 1080, y: 712, s: 0.4, k: 0.3, rot: -0.1, tone: 'day' })`
- 注: figures.js の `coupleSittingBack({earphones:true})` は、人物のシルエットの中に簡略なコードを自前で描く。並んで座る引きの画ではそちらを使う。こちらと同時に使うとコードが二重になるので、手元や耳元のアップ、差し出すカットだけこちらを使う。

## 4. `PV.lib.phone(ctx, t, o)` — スマホ
- **アンカー**: 本体の中心。**自然サイズ**: 300×620（縦）。手に持たせるときは `s≈0.6〜0.8`、画面のアップは `s≈1.5`。
- 影と筐体（下層）、ガラスの艶と縁（上層）はスプライトにキャッシュし、**画面の中身だけ毎フレーム描く**。`o.cache:false` にすると全部ベクターで描く。
- `o.screen`:
  - `'message'`: 吹き出し。`o.messages=[{text, me, time?, read?, at?}]`（`me:true` が右側の自分）、`o.name`（ヘッダ, 既定「先輩」）、`o.reveal`（1通あたりの秒数。指定すると順番にポップインする）、`o.typing`（「…」入力中）、`o.clock`。日本語は自動で折り返す（句読点の禁則あり）。
  - `'player'`: 再生画面。`o.title`（**既定は原作の架空曲〈放課後の音楽室〉**。実在の曲名やアーティスト名は出さないこと）、`o.artist`、`o.progress`（0..1）または `o.duration`（秒。t から進む）、`o.length`（曲の長さ s）、`o.paused`、`o.drawArt(ctx,w,h,t)`
  - `'photo'`: `o.drawPhoto(ctx, w, h, t)` で画面内（0,0〜w,h、クリップ済み）に写真を描く。`o.caption`、`o.ui:false` で UI を消す
  - `'off'`: 黒い画面に**自分の顔がぼんやり映る**（`o.reflect` 0..1, 既定 0.6。静的なのでスプライトに含まれる）— 第三十五話「真っ黒な画面…自分の顔が映っている」
  - `'call'`: 着信（`o.name`, `o.sub`、波紋が広がる）。`o.vibrate: true` で本体が震える（1.6s 周期）
  - `'lock'`: ロック画面（`o.clock`, `o.date`, `o.notice={app,title,text,when}`, `o.noticeAt` 秒で通知がスライドイン）。ステータスバーに時計は出さない。長い通知は「…」で省略する
  - `'none'`: 画面なし（消灯したガラスだけ）
- `o.notify: true | '#hex'` 上部ベゼルの**通知ランプが明滅**する（1.6s 周期。裏向きのときは縁から光が漏れる）。`o.glow` 0..1 画面の光が周囲へ漏れる量。`o.bright` 画面の輝度。`o.back: true` 裏面（伏せた状態, `o.case` 色）。
- 平置き: シーン側で `ctx.scale(1, 0.56)` などをかけてから呼ぶと、机に寝かせた見た目になる（`dev_props_8` 参照）。

## 5. `PV.lib.handCream(ctx, o)` — 誕生日プレゼントのハンドクリーム
- **アンカー**: 配置の中心（机の面）。**自然サイズ**: 約 520×300（ギフト箱つきは約 600×520）。
- **見た目**: アイボリーのチューブ（セージグリーンのラベル「fleur de pommier / HAND CREAM」、林檎の花のマーク、シャンパンゴールドのキャップ、圧着した端）と、持ち歩き用の**アルミの丸缶**（ヘアライン加工の円錐状の反射、刻印）。ブランドは架空。
- `o.tube`（既定 true）、`o.tin`（既定 true）、`o.open: true`（缶の蓋が外れて、渦を巻いたクリームが見える）
- `o.giftBox: true` — **開けたプレゼント**: セージ色の箱（正面に金箔のロゴ）、後ろに立て掛けた蓋（金箔の枠とロゴ）、**角の立った薄紙のひだ**（面ごとに陰影をつけ、角が箱から飛び出し、手前と右の縁に垂れる）、**薄紙に埋まった缶**、テーブルにほどけて捩れる**サテンのリボン**（表と裏で色が違い、端は燕尾）。チューブは箱の手前に置く。
- `o.tubeAt {x,y,rot}`, `o.tinAt {x,y}`: チューブと缶の位置（アンカー相対）。既定はチューブ (-95,48,-0.2)、缶 (205,-52)。ギフト箱のときはチューブ (60,150,-0.1)。
- 黒い鏡面（ピアノの蓋）に映すときは、物体ごとに接地線で鏡像を作る（箱は `tube:false`、チューブは `tin:false, tubeAt:{x:0,y:0}` で別々に呼ぶ）。`dev_props_11` を参照。

## 6. `PV.lib.necklace(ctx, t, o)` — 細いチェーンの控えめなネックレス
- **座標系**: スクリーン座標。
- `o.mode`:
  - `'worn'`（既定）: `o.a`, `o.b`（首の左右）の間に U 字に垂れる。`o.drop`（垂れ量 px, 既定 90）。最下点にペンダント。首は人物側で描く。
  - `'hang'`: `o.a`（指先）から二重に垂れて揺れる（`o.len`, `o.swing`）
  - `'laid'`: 机の上にゆるく置いた輪（`x, y, o.r`）
- `o.pendant 'drop'`（小さな雫形の石, 既定）| `'pearl'`、`o.metal 'silver'|'gold'`、`o.size`、`o.sparkle` 0..1。チェーン上を**短い光の筋がゆっくり走り**、その先端で小さな星がまたたく。石も時々キラッと光る（t）。

## 7. `PV.lib.handkerchief(ctx, t, o)` — ハンカチ
- `o.mode 'held'`（既定）: `(x, y)` = つまんでいる点。角から垂れ下がる布（離れるほどひだが増える）。`o.wind` 0..1 で揺れる。差し出すカット用。自然サイズは `o.size` 300 で長さ約 300。
- `o.mode 'folded'`: `(x, y)` = 中心。**四つ折りで置いたハンカチ**（スプライト）。柔らかく少し波打つ輪郭、開いた側（右と手前）の縁に重なる4枚の層、折り山の丸みと折り返しの影、厚み、ふくらみ、刺繍の花。`o.pattern:'border'` のボーダーは、四つ折りなので開いた2辺にだけ出る。`o.k` は奥行きの潰れ（既定 0.62）。
- `o.color`（既定は淡い水色 `#bcd5ec`）、`o.pattern 'check'`（ギンガム, 既定）| `'plain'` | `'border'`。暗いシーンでは必ず `tone` を合わせる（白い布が発光して見えるのを防ぐ）。

## 8. `PV.lib.umbrella(ctx, t, o)` — 開いた傘（雨粒が伝う）
- **アンカー**: 傘の先端（石突き = 頂点）。**自然サイズ**: 半径 `o.r` 330（直径 ≈ 660）＋柄 `o.shaft`（既定 1.5r）。
- `o.type 'vinyl'`（透明ビニール, 既定: 透けるパネル、白い骨と縁のテープ、無数の水玉。柄は透けて見える）| `'navy'`（紺の布。**上から見ているとき柄は布に隠れ、下から見ているときだけ布の手前に描く**）
- `o.elev`（カメラの仰角 rad, 既定 0.28 = やや上から。負なら下から）、`o.yaw`、`o.tilt`（傘全体の傾き rad）、`o.ribs`（8）、`o.spin`
- `o.rain` 0..1: 表面の水玉、パネルを**滑り落ちる雫**、骨の先から**滴って落ちる雫**（t でループ）
- 相合傘で右肩が濡れるカットは figures.js の `coupleUmbrella` と組み合わせる。傘のアップはこちらを使う。

## 9. `PV.lib.ecgMonitor(ctx, t, o)` — 病室の心電図モニター
- **アンカー**: 筐体の中心。**自然サイズ**: 560×420（取っ手込みで高さ ≈ 460）。
- **見た目**: オフホワイトの筐体。暗い画面に緑の ECG（II 誘導）、水色のパルスオキシ波形、黄色の呼吸波形がスイープ描画される（書き込みヘッドの光点と消去ギャップ）。HR/SpO₂/NIBP/RR の数値、鼓動ごとに光るハートと**緑のランプ（ピッ）**。画面の光が周囲に漏れる。筐体はスプライトにキャッシュしてある。
- `o.bpm`（68）、`o.spo2`（98）、`o.nibp`（'116/74'）、`o.rr`（16）、`o.mode 'sweep'|'scroll'`、`o.speed`（px/s, 110）、`o.mount: true`（壁のアーム）、`o.screenGlow` 0..1、`o.phase`、`o.clockBase`（秒）
- **音合わせ**: 拍の時刻は `t = o.phase + n·60/bpm`（R 波は拍頭 +0.222s）。`PV.lib.ecgBeat(t, bpm, phase)` が直前の拍からの経過秒を返すので、効果音の「ピッ」と同期できる。

## 10. `PV.lib.ivDrip(ctx, t, o)` — 点滴
- **アンカー**: 袋を吊るすフック。**自然サイズ**: 袋 150×250 ＋点滴筒＋チューブ（全高 ≈ 760）、スタンド `o.poleLen` 900。

## 既知の制約
- 弁当は平行投影に遠近の補正をかけた見せ方なので、カメラが前後に大きく動くカットでは、具材どうしの奥行きのずれ（パララックス）は出ない。ゆっくりした押し引きは `s` の変化で十分に見えるが、回り込むカメラワークには向かない。
- 拡大縮小が続くカットでは、キャッシュ解像度の区切り（√2 刻み）を越えるたびに1回だけ再描画が入る。`cacheScale` で固定する。
- `view:'top'`（ほぼ真上）では、タコさんの目は前脚に隠れて見えない（顔を見せたいカットは `angle` を使う）。
- 夜の場面のケーキなど白い小物は、トーンだけでは明暗差が出にくい。シーン側で光源の向き（`light`）とリムの色を必ず決めること。
