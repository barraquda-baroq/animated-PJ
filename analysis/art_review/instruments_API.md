# instruments.js — 楽器・音楽室ライブラリ API

`pv/engine/lib/instruments.js`。名前空間は `PV.lib`（以下 `L`）。Canvas2D だけを使い、`Math.random` は使わない（決定論的）。
ショーケースは `pv/scenes/_dev_instruments.js`（`dev_instruments_1`〜`10`）、最新の確認画像は `analysis/art_review/instruments_review/r3/`（総覧は `showcase_overview.jpg`）。美術監督チェックの記録は `analysis/art_review/instruments_critique.md`。

## 共通の約束

- **3D アセット**（ピアノ、鍵盤、指板、音楽室、ホール、体育館、窓）は内部で小さなピンホールカメラ（右手系、y が上）を使い、透視投影で描く。単位はアセットごとに違う（ピアノと部屋はメートル、鍵盤と指板はミリ）。
- **2D アセット**（アコギ、ストラト、アンプ、楽譜）はセル調の平面画。`x, y, len/h/w, rot` で配置する。
- 戻り値の画面座標は、呼び出し時の `ctx` の変換を**かける前**の座標。シーン側で `PV.camera()` を使う場合は同じ変換の中で使う。
- **キャッシュ**: 静的な層は内部の `cachedLayer` に保存する（スロットごとに最大2件、カメラや時間帯が変わると作り直す）。
  - 最初のフレームはキャッシュ作成で 0.2〜1.3 秒かかる。2フレーム目からは速い。
  - キャッシュは恒等変換で描き、現在の `ctx` 変換の下で `drawImage` する。そのため `PV.camera()` による 2D のパン、ズーム、回転はほぼ無料。
  - 一方で `camX` などの **3D カメラ移動はフレームごとに作り直しになり重い**（音楽室で 150〜200ms）。本物の視差が要るカット以外は「3Dカメラを固定し、2Dでドリフト」を推奨する（ショーケース 1, 4, 8 がこの方式）。
- **目安時間**は、ラスタライズを強制（描画後に `getImageData`）し、ポストプロセスを外して、キャッシュ作成後の中央値を測ったもの。エンジンのポストプロセスは別に 120〜180ms かかる。
- 光源の色は美術ガイドに合わせてある（春の音楽室 `#fff1d4`、雨 `#8a97ab` 系、夕暮れ `#ffb069`、ホールのスポット `#fff1d8`、体育館 `#ffbf6b / #ff5fa8 / #5fd7ff`、白い世界 `#f8f8f6`）。
- 依存: `atmos.js` の `L.clouds`、`L.haze`、`L.rain`、`L.dust`、`L.glow`（無くても描画は壊れず、その要素だけ省かれる）。

## 1. `L.grandPiano(ctx, o)` → グランドピアノ（3D、メートル）

黒鏡面のグランドピアノ。脚、キャスター、ペダル、譜面台と楽譜、鍵盤 88 鍵も描く。

映り込みと艶:
- ケース側面のカーブには、環境（窓）の映り込みの縞が出る。湾曲で視線から逸れる所はフレネルで明るむ（`sheen`）ので、黒い曲面として読める。
- 閉じた天屋根は漆黒で、窓だけがくっきり鏡像として映る（白く洗われない）。
- 開いた天屋根の裏には、金色のフレームと弦の扇が鏡像で映る（`lidGold:false` で無し）。
- 正面から見た天屋根は、ほぼ真横から見るので、黒い刃のような板になる。

`style:'silhouette'` の影絵は中まで塗りつぶす（内部、鍵盤のベッド、ケース前面の両端も塞ぐので、逆光の窓が透けない）。淡い内側の輪郭線（リム上端、天屋根の縁、鍵盤の線）でグランドピアノと読ませる。

| オプション | 既定値 | 説明 |
|---|---|---|
| `view` | `'side'` | `'side'`（客席側から見た側面。左が鍵盤、右が尾）、`'threeQuarter'`（鍵盤側の斜め前）、`'front'`（奏者側の正面）。`yaw`, `pitch`, `roll`（rad）で任意の角度も指定できる |
| `x, y` | `960, 885` | ピアノの平面中心の**真下の床の点**を置く画面座標 |
| `scale` | `330` | 中心位置での px/m。2m のピアノはおよそ `scale*2` px |
| `dist` | `8`（front は `4.2`） | カメラ距離（m）。小さいほどパースが強い |
| `length`, `width` | `2.0`, `1.49` | 全長と幅（m）。コンサートグランドは `length: 2.75` |
| `lidOpen` | `0.8` | 天屋根の開き 0〜1（1 で約34°、突上棒付き） |
| `bench`, `desk`, `sheet` | `false, true, true` | 椅子、譜面台、譜面台上の楽譜 |
| `style` | `'lit'` | `'silhouette'` は単色の影絵（`color` 既定 `#0b0f1a`）に光側のリムライト（`rim`, `rimDir` は画面上で光のある方向の角度 rad、既定 -2.3＝左上、`rimColor`, `rimAlpha`, `rimWidth`）。内側の輪郭線は `innerLines`（既定 true）、`innerAlpha`（既定 0.32） |
| `sheen` | `1` | ケース側面のフレネルの艶の強さ（0 で物理どおりの暗い側面） |
| `lidGold` | `true` | 開いた天屋根の裏に、金のフレームと弦を映す |
| `rimLit` | — | `true` または `{dir, width, color, alpha}`。lit 描画にリムライトを足す（窓の逆光カット用） |
| `light` | `'left'` | 映り込み用の窓壁の位置。`'left'`、`'right'`、`'back'` |
| `lightColor`, `lightK`, `roomK`, `lacquer` | | 映り込みの色と強さ、漆の地色 |
| `env` | — | `'stage'` にするとホール照明（前上方のスポット）の映り込みになる |
| `roomCam, at:[x,z], rotY, roomEnv, lightDirRoom` | — | 外部の 3D シーンの中に置く。通常は `musicRoom()` の戻り値 `R.piano()` を使う |
| `shadow` | `0.55` | 床の影の濃さ。0 で影なし |
| `cache` | `false`（`R.piano()` 経由では `true`） | 完成画像をキャッシュする。毎フレーム同じピアノを描くとき用 |

**戻り値**は `{cam, keyboard:[x,y], desk, lidTop, floor, bench, scale, bbox}`。`keyboard` は鍵盤中央、`bench` は椅子の座面で、人物（奏者の後ろ姿）を配置するアンカーに使う。

**推奨サイズ**は `scale` 150〜450。それより大きいアップでは鍵盤に `keysClose` を使う。

**目安時間**: lit 約20ms（3/4、scale 200）、silhouette 約36ms、部屋の中で rimLit 付きかつキャッシュあり（2フレーム目以降）は約2ms。

```js
const R = L.musicRoom(ctx, t, { view: 'windows', time: 'noon' });
L.grandPiano(ctx, R.piano(8.7, 3.25, -0.42, { lidOpen: 1, bench: true, rimLit: true }));
L.grandPiano(ctx, { view: 'threeQuarter', x: 900, y: 800, scale: 260, style: 'silhouette', rimDir: -2.0 });
```

## 2. `L.keysClose(ctx, t, o)` → 鍵盤のクローズアップ（3D、ミリ）

座標系: x は鍵盤に沿う方向（A0 の左端から。白鍵 1 本 = 23.5mm）、y は上（白鍵の上面 = 0）、z は奥（白鍵の手前 = 0、名札板 = 153）。

白鍵と黒鍵は面取りした立体として描く。窓の鏡像による光沢、黒鍵の柔らかい影、名札板（黒漆）への鍵盤の映り込み、赤いフェルトも描く。

- 黒鍵の上面は漆黒で、手前に淡い艶がある。光側の長辺の面取りには鋭いハイライトが入る（灰色の板には見えない）。
- 押した鍵は奥の支点を軸に沈み、隣の鍵の側面が、実際に見える深さだけ覗く。
- **キャッシュ**: カメラと光が固定なら、押鍵のない鍵盤を一度だけ描いてキャッシュする。各フレームでは、押した鍵の近傍（手前で重なる鍵も含む）だけを別バッファで描き直し、1 回で貼る。押鍵なしで約1ms、1 鍵で約15ms。`warp` を使うときと `cache:false` のときは毎フレーム全部を描く。

| オプション | 説明 |
|---|---|
| `view` | `'along'`（右手前から斜めに見るクラシックな構図。既定）、`'alongBass'`、`'low'`（極端なローアングル）、`'side'`、`'front'`（奏者の視点）、`'top'` |
| `focus` | 中心にする鍵の index（0..87、既定 39 = C4） |
| `pressed` | `{index: 0..1}`。沈み込み（1 = 10mm） |
| `light` | `{az, el, color, k, winW, winH}`。光の来る方向（az は水平角 rad、el は仰角）、色、強さ、窓の大きさ |
| `ambient`, `ivory` | 環境色と白鍵の色 |
| `dof` | `{amount: ぼけpx, range: ピントの合う鍵数}` または数値。ピント帯の外を 1/6 解像度でぼかす（背景も一緒にぼける） |
| `warp`, `whiteout` | 0..1。鍵盤が波打って歪み、白く溶ける（「鍵盤が歪んでいる。見たことのない形に」）。whiteout は露出オーバー型で、明部から発光して滲み、最後は紙の白（`#f8f8f6`）になる |
| `cache` | 既定 true。押鍵のない鍵盤のキャッシュと、押鍵の差分の描き直し（上記） |
| `cam` | `{eye, tgt, fov}`。プリセットの上書き（鍵盤座標の mm、絶対値） |
| `fov`, `zoom`, `cx`, `cy`, `roll`, `style:'silhouette'` | |

**`L.keyPos(o, index)`** は、`keysClose` に渡すのと**同じ `o`** を渡すと、その鍵の指先位置を返す: `{x, y, depth, w (鍵幅px), ax, ay (鍵盤に沿う画面単位ベクトル), bx, by (鍵の奥方向), scale (px/mm), black, press, front:{x,y} (鍵の手前の縁), note (MIDI)}`。手のアセットを重ねるときに、位置、回転（`atan2(ay, ax)`）、大きさの基準にする。

**`L.keyIndex('C4')`** は 39 を返す（`'F#5'`, `'Bb3'` なども可）。

**目安時間**: 押鍵なしで約1ms、1 鍵で約15ms、遠い和音と近い鍵の 2 か所で約33ms、それに dof を足して約42ms。warp＋whiteout はキャッシュが使えず約47ms（転換の 1〜2 秒用）。

## 3. `L.fretboard(ctx, t, o)` → ギターのネックのクローズアップ（3D、ミリ）

座標系: x はナット (0) からボディ方向（スケール 648mm）、y は 1 弦側、z は指板の法線。

メイプル指板（年季の入った塗装の擦り減り、木目、黒ドット、側面ドット）またはローズウッドを選べる。弦の影も描く。

- フレットは半円断面（2.4×1.15mm）のニッケル線材。8 面に分けて陰影を付ける。下面は指板の色、上面は部屋を映し、光を鏡面反射する所に鋭いハイライトが入る。
- 弦は 6 本。プレーン弦は鋼、巻弦はニッケルの明度で、鋭い鏡面線が入る。巻弦は画面上の太さに応じて巻き目の斜線が見える。

| オプション | 説明 |
|---|---|
| `view` | `'snap'`（弦が切れる見せ場用。斜め上からの寄り）、`'along'`（ネックに沿うローアングル）、`'player'`（奏者の視点。ヘッドが左、1弦が上）、`'audience'`（客席の視点。ヘッドが右、6弦が上）、`'low'` |
| `focus` | 中心に置くフレット番号（既定 12） |
| `wood` | `'maple'`（既定。母の形見のストラト）または `'rosewood'` |
| `wear` | メイプルの擦り減りの強さ（0 で無し） |
| `vibrate` | `[1弦..6弦]` 0..1。振動のぶれ（2 位相の残像と包絡線のもや） |
| `press` | `{弦index: フレット}`。押さえている弦 |
| `snap` | `{string:0 (1弦), p, at (フレット), bend (mm, 既定 8), width (切れ端の誇張倍率, 既定 3), lines}`。`p<0` はチョーキング。-1→0 で、切れる瞬間に向かって押し曲げが強まり、最後に微振動する。押し曲げはフレット付近に集中するので、アップでも読める。`p≥0` は切れた後。閃光（長さの不揃いな針状の光と、横に伸びる光条）、火花、集中線が出る。両端は、白熱した芯のグローと残像の帯を引きながら、丸まって跳ね戻る。0→0.3 が一番の見せ場で、`p` の進め方（スロー）はシーン側で決める |
| `light` | `{az, el, color, k}`（ステージの色光を当てる）。ほかに `ambient`, `cam:{eye,tgt,up,fov}`, `fov`, `zoom`, `cx`, `cy`, `roll` |

**`L.fretPos(o, string, fret)`** は、その弦とフレットを押さえる指先の位置を返す: `{x, y, depth, ax, ay (ネックに沿う方向), bx, by (6弦側), scale (px/mm), spacing (弦間隔px)}`。**`L.fretX(n)`** は n フレットのナットからの距離（mm）を返す。

**目安時間**: 静止時は約6ms（指板とフレットはキャッシュ）、切れる瞬間は約22ms。

## 4. `L.acousticGuitar(ctx, o)` → 傷だらけのアコースティックギター（2D、セル調）

ドレッドノート型。経年で琥珀色になったスプルース（`finish:'sunburst'` も可）、べっ甲柄のピックガード、ロゼッタ、ブリッジとピン、ローズウッド指板。

経年の表現として、ピックの擦り傷で白木が見える部分、全面の引っかき傷と打痕、塗装のウェザーチェック、腕の当たる場所の擦れ、バインディングの欠けを入れてある。

| オプション | 説明 |
|---|---|
| `x, y` | 楽器全体の中心（ネックとボディの境のあたり） |
| `len` または `scale` | 全長（px）または px/mm。既定 0.8 px/mm でおよそ 850px |
| `rot` | 回転（rad）。0 でヘッドが上 |
| `flip` | 左右反転 |
| `light` | 光の来る画面角度（rad、既定 -2.25＝左上）。セルの影とハイライトの向きになる |
| `ambient` | 0..1。暗い部屋でのトーン |
| `tilt` | -1..1。ボディ側面の厚みを見せる |
| `style` | `'silhouette'`（`color`） |

**推奨サイズ**は全長 300〜1000px。**目安時間**は約7ms。

## 5. `L.strat(ctx, o)` → 塗装の剥げた白いストラトキャスター（2D、セル調）

経年で黄ばんだ白のボディ。剥げた箇所は、黄ばんだ下塗りの縁取りの内側にアルダー材の木目が見える。腕の当たる場所、縁、底辺の剥げ、欠けと傷も入れてある。

ほかに 3 層ピックガード、シングルコイル 3 基（リア側は斜め）、ノブ 3 個、5way スイッチ、ジャックプレート、トレモロブリッジとアームを描く。メイプルネックには低フレットの手垢の擦れと黒ドット、ヘッドには片側 6 連のペグとストリングガイドがある。

ボディは実寸の比率（全長 406mm、幅 322mm）にしてある。12 フレットまで伸びる尖ったベース側の角（ペグのある側）、短く丸い高音側の角、U 字のカッタウェイ、細い上胴、緩いくびれ、丸く広い下胴という形なので、シルエットでもストラト系と読める。

オプションは `acousticGuitar` と同じ（`x, y, len|scale, rot, flip, light, ambient, style, color, seed`）。既定 0.85 px/mm でおよそ 790px。ロゴは描かない（実在ブランドを避けるため）。ローカル座標（mm）は、ナットが y=0、ブリッジのサドルが y≈648、ボディが y 332〜740、ネックの中心線が x=0、ベース側が −x。**目安時間**は約5ms。

## 6. `L.amp(ctx, t, o)` → 小型ギターアンプ（2D＋疑似奥行き）

黒いトーレックス、ツイード調のグリル（`grille:'black'` も可）、操作パネル（ジャック、目盛り付きノブ）、ハンドル、角を包む丸いコーナー金具、パイロットランプを描く。パイロットランプはカット面のある赤いジュエルで、点灯中は芯、ハロー、パネルへの赤い滲みが出て、わずかに揺らぐ。天板の縁と奥の稜線に部屋の光のリムが入るので、暗い部屋でも輪郭が溶けない。

| オプション | 説明 |
|---|---|
| `x, y` | 底辺中央（床の接地点） |
| `h`, `w` | 高さ（px、既定 320）。幅（既定 `h*1.12`） |
| `view`, `angle`, `topView` | `'front'` または `'threeQuarter'`。`angle` は側面の見え方（±、既定 0.35）、`topView` は天板の見え方 |
| `lamp` | 0..1。ランプの明るさ（0 で消灯。「赤い光がゆっくりと消える」） |
| `ambient` | 0.03..1.5。本体の明るさ（暗い部屋ではランプだけが光る） |
| `knobs` | `[0..10]×5`。ノブの指す値（「ボリュームを絞って」） |
| `glow` | ハローの半径係数 |
| `shadow` | 床の影 |
| `rim`, `rimColor` | 稜線のリムの強さ（既定 0.55、0 で無し）と色（既定 `#9fb0d8`。夜の窓の光） |
| `style` | `'silhouette'` |

**戻り値**は `{lamp:{x,y}}`（ランプの画面位置。追加のグローやレンズフレア用）。**目安時間**は約10ms。

## 7. `L.sheetMusic(ctx, t, o)` → 楽譜のページ＋「楽譜が、一斉に、消えた」

A4 のページに大譜表を 6 段描く。ト音記号とヘ音記号（パス描画）、調号（♭5 つ＝変ロ短調。「雪あらし」の調）、拍子、連桁の付いた 16 分音符の和音、低音部、休符、スラー、強弱記号（*ff pp sf mf*）、ヘアピン、cresc./dim.、運指を入れてある。タイトルは "Études d’exécution transcendante / No.12 Chasse-neige / F. Liszt"（パブリックドメイン）。

| オプション | 説明 |
|---|---|
| `x, y` | ページ中心 |
| `w` | ページ幅（px、既定 640）。高さは幅の 1.414 倍 |
| `rot`, `skewX`, `scaleY` | 譜面台に置いたときの傾きや見下ろしの擬似パース |
| `dissolve` | 0..1。音符が小片ごとに紙から剥がれ、インク→金→光と色を変えながら舞い上がる。光の段階は加算合成なので、暗い背景の上でも煤ではなく光の粒になる。五線は紙の上で薄れ、紙は真っ白になる（`dissolve` 1 で白紙）。残ったインクは差分で消していく（`dissolve` が戻れば作り直す） |
| `rise` | 舞い上がる高さの倍率 |
| `seed`, `paper`, `ink`, `light:{angle}`, `shadow` | |

**戻り値**は `{corners}`（ページ四隅の画面座標）。**目安時間**は静止時約6ms（インク層はベイク済み）、消滅中は 25〜38ms。

## 8. `L.musicRoom(ctx, t, o)` → 音楽室の背景（3D、メートル）

座標系: 部屋は x 0..14（長手方向、x=14 が黒板の壁）、z 0..9（z=0 が窓の壁）、天井は 3.0m。

部屋の内容:
- 窓は 4 スパンで、アルミのサッシ（引き違い）、欄間、窓台の厚み（見込み）がある。
- 窓間壁がある（「窓間壁の近く、いい具合に陽が当たらない席」の椅子もある）。
- 白いレースのカーテンが風でふくらむ。窓ガラスの前では透けて明るく、壁の前では沈む。
- 有孔ボードの壁と腰板、吸音天井と蛍光灯、木の床（板目と継ぎ目、窓のにじんだ映り込み）がある。天井は日だまりの真上だけ照り返しで明るく、窓上とカメラ側は沈む。
- 廊下側の壁には、ガラス窓の付いた引き戸 2 枚、紙の貼られたコルクの掲示板、欄間窓がある。
- 黒板は五線入りで、チョークの音符がある。その上に作曲家の肖像画と時計を掛けてある。
- 椅子と譜面台がある。椅子は合板と鋼管で、天板は明るく、垂直面は上から下へ暗い。縁線と接地の陰もある。

光の表現: 窓ガラスの区画の形をした日だまりが床に落ち、光芒が差す（半解像度でキャッシュし、全体をゆっくり明滅させる）。光芒の中に塵が舞う。家具の影も床に落ちる。

窓の外には空、雲、向かいの校舎、桜と若葉の木が見える。木は塊を 3 段の明度で重ねて描く。夕方は下から照らされた層雲の筋と小さな雲、雨の日は雨と雨粒、ガラスを伝う水滴も描く。色調整（soft-light）はキャッシュ層に焼き込んである（窓の穴は除く）。

| オプション | 説明 |
|---|---|
| `view` | `'windows'`（窓の壁を正面に見る逆光の構図。既定）または `'room'`（教室を奥に見る一点透視。左に窓、奥に黒板） |
| `time` | `'noon'`、`'rain'`、`'dusk'` |
| `open`, `wind` | 窓の開き 0..1（雨の日の既定は 0）、カーテンにかかる風 0..1 |
| `furniture` | `'full'`、`'sparse'`（構図を空ける）、`'none'` |
| `camX, camY, camZ, lookX, lookY, zoom, roll, cam:{eye,target,fov}` | 3D カメラ。動かすと重いので「共通の約束」を参照。`'windows'` の既定の視線は目標の高さ 1.34m（窓と床が主役の水平な構図）。以前の天井多めの構図は `lookY: 0.14` で戻せる |
| `lightsOn`, `shaft`（光芒の倍率、0 で無し）, `dust`（false で無し）, `curtainAlpha` | |

**戻り値**は `{cam, env, time, shafts, seat:[x,y], project(p), piano(x,z,yaw,extra)}`。
- `R.piano()` を `grandPiano` に渡すと、同じカメラで部屋の実際の窓（と床の日だまり）が映り込み、日差しの方向も揃う。
- `R.project([x,y,z])` は部屋の座標を画面座標に変える（人物の配置用）。
- `seat` は窓間壁の席の座面の画面座標。

**推奨**: 窓の逆光カット（ショーケース 1）は `view:'windows'`、`furniture:'sparse'`、ピアノは `rimLit` 付きで置く。

**目安時間**: 1フレーム目は約1.1秒（キャッシュ作成）、2フレーム目以降は約29ms（`'room'` 夕は約25ms、雨は約16ms）。ピアノ（キャッシュあり）を加えて約30ms。

## 9. `L.windowCurtain(ctx, t, o)` → 窓とカーテン単体（3D、正面、メートル）

窓の開口部（1.9×1.6m）、サッシ、クレセント錠、窓台の見込み、外の景色（`time` 別）、ガラスの反射を描く。雨の日はガラスに付いた水滴と、筋を引いて流れる水滴も描く。水滴は小さなレンズとして描き、上に暗い地面、下に明るい空が反転して映り、光点が 1 つある。カーテンは左右 2 枚で、隙間（`gap`）がある。ひだの間隔と深さはレールに沿って揺らぎ、縦縞には見えない。

| オプション | 説明 |
|---|---|
| `x, y, w, h` | 描画する矩形（既定は全画面） |
| `time` | `'noon'`、`'rain'`、`'dusk'` |
| `rain` | 0..1（雨の日の既定は 1） |
| `open`, `wind` | 窓の開き、風（窓が開いていればカーテンが揺れる） |
| `gap` | 0..1。カーテンの切れ目（先輩が立つ隙間） |
| `grip` | `{side:'left'|'right', v (高さ 0=上 1=下), pull 0..1}`。手で握られたカーテン。握った点に向かって布が寄り集まり、縁が隙間側へ引かれる。握った所から張ったひだが放射状に伸びる（「カーテンを握る手が、小さく、震えていた」） |
| `camX, camY, roll` | |

**戻り値**は `{cam, grip:[x,y] (握り点の画面座標。手のアセット用), sill, gapCenter}`。**目安時間**は約32〜40ms。

## 10. `L.concertStage(ctx, t, o)` → コンクールのホール（3D、メートル）

舞台は y=0、z は 0 が舞台の縁で、負の方向が奥。

描くもの: 木の反響板の奥壁、袖、磨かれた黒い床（ピアノの映り込み）、エプロン（舞台の縁）、ボーダーライト、スポットの光芒と床の光の溜まり（塵が舞う）。ピアノはフルコンサートグランド（2.75m）で、天屋根を全開にし、椅子を置き、スポットのリムライトを当てる。手前には暗い客席の背もたれを並べる。

| オプション | 説明 |
|---|---|
| `view` | `'audience'`（客席前方から）、`'stage'`（舞台上の斜めから）、`'wide'` |
| `whiteout` | 0..1。ホールが真っ白（`#f8f8f6`）に溶けてピアノだけが残る。輪郭は光に侵食され、床の代わりに淡い影だけが浮く（「真っ白に、輪郭を失った世界…ピアノだけが浮かんでいる」）。白の世界では、ピアノを「白い環境を映す黒い漆」で描き直した層に切り替わる（縁が白く光り、天屋根裏の金は映らない白黒の絵）。`floatShadow` で影の濃さを変える |
| `spot`, `spotColor` | スポットの強さと色 |
| `pianoAt:[x,z]`, `pianoYaw`, `lidOpen`, `bench`, `piano:{grandPiano の追加オプション}` | ピアノの配置と設定 |
| `seats` | false で客席なし |
| `camX, cam, zoom, roll` | カメラ |

**戻り値**は `{cam, piano (grandPiano の戻り値), bench, keyboard, project}`。ドレス姿の先輩を `bench` か `keyboard` に合わせて置ける。**目安時間**は約16ms、whiteout 中は約24ms（ホール、スポット、ピアノ、白の世界のピアノは層ごとにキャッシュ）。

## 11. `L.gymStage(ctx, t, o)` → 文化祭の体育館の即席ステージ（3D、メートル）

原作では「ステージはなく、観客と同じ目線。気持ち程度のロープ」とある。それに合わせ、床の上を演奏スペースにした。

描くもの:
- 奥に閉じた緞帳の舞台、「文化祭」の横断幕、紙の飾り。体育館の暗幕、トラス、畳まれたバスケットゴール、コートラインの入った床。
- 控え室にしたパーティション（アルミ枠と T 字脚の布パネル）、ロープの柵（クロームのポールと丸い台座、赤いロープ）。
- 機材は 3D で、ステージの照明（琥珀のキー、マゼンタのフィル、シアンとマゼンタの逆光）で陰影を付ける。
  - ドラムセット: ワインレッドのスパークルの胴、クロームのフープとラグ、ポート穴付きのバスドラム、スネア、タム 2 つ、フロアタム、旋盤目の入ったシンバル 3 枚とハイハット、三脚スタンド。
  - X スタンドの 61 鍵キーボード。
  - ギターアンプとベースアンプ（赤いランプ点灯）、マイクスタンド、三脚のライト。
- 色付きの光芒（琥珀、マゼンタ、シアン）がゆっくり振れ、床に光の溜まりを落とす。全体にもやがかかる。
- 手前に観客の後ろ姿のシルエットを置く。
  - 首、水平な肩の線、髪型（ロング、ポニーテール、ボブ、短髪）を描き分ける。
  - 奥ほどもやで明るく、手前ほど黒い。
  - 挙げた腕は肘で曲がり、拳、ピース、スマホ（画面の光が縁から漏れる）を持つ。
  - 色付きのリムライトを当てる。

| オプション | 説明 |
|---|---|
| `crowd` | `'standing'` または `'sitting'` |
| `crowdCount` | 観客の人数 |
| `crowdGap` | 中央を空ける幅（m、既定 1.0。演奏者の見える通り道） |
| `hands`, `audience`, `seed` | 挙げた手の有無、観客の有無、配置のシード |
| `beams` | 0..1。光芒の強さ |
| `flash` | 0..1。白っぽい琥珀色のフラッシュ（弦が切れた瞬間の「歓声」） |
| `colors` | `[3色]`。光芒の色 |
| `lamp` | アンプのランプ |
| `banner` | 横断幕の文字 |
| `view:'close'`, `camX, cam, zoom, roll` | カメラ |

**戻り値**は `{cam, project, performer (演奏位置の床の点), keyboard, amp}`。**目安時間**は約28ms（ホール、機材、観客、もやはキャッシュ。光芒と光の溜まりは半解像度のバッファ 1 枚）。
