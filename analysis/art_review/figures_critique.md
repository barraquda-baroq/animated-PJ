# figures.js 総作画監督チェック（講評と修正記録）

対象: `pv/engine/lib/figures.js`（`PV.lib.*` 人物シルエット12関数）／ショーケース `pv/scenes/_dev_figures.js`（`dev_figures_1`〜`11`）
初回チェック画像: `analysis/art_review/figures_review/r0/`（0.5/2.5/4.5 秒、`r0_sheet_N.jpg`）
判定基準: 美術・作画スタイルガイド、作画アセット共通ブリーフ（1関数 40ms 以内、決定論的、save/restore）。

担当者の報告（「全シーン問題なし、弱点は大アップ時の線の多さ程度」）は甘い。**報告で「修正済み」とされた少年の後頭部は、相合傘・ベンチ・芝生の後ろ姿でまだ横顔に見える。** さらにスタイルガイドの最重要要件「シルエットで二人が見分けられること（彼女＝長い髪のライン）」が後ろ姿の構図で守られていない。以下、重大度順。

---

## A. 致命的（このままPVに出すと画として成立しない／意図と逆に読める）

### A1. 少年の後頭部が「右を向いた横顔」に読める（ベンチ・相合傘・芝生）
- `boyHairBack` の右側の房（風下側）が外へ突き出し、その上が凹むため、額→鼻→顎のシルエットができる。`dev_figures_3`（中庭ベンチ）では少年が右を向いて横顔を見せているようにしか見えない。後ろ姿の構図が「振り向いている」に化ける。
- 報告では「抱擁と後ろ姿では修正済み」とあるが、未修正。
- **直し方**: 後頭部を左右ほぼ対称の凸な丸みに。房は下向き（襟足・耳の後ろ）にだけ出し、風は房先を少しずらすだけにする。外形に凹みを作らない。

### A2. 後ろ姿で彼女の長い髪が見えない（ベンチ・相合傘・芝生・欄干の弱風時）
- 髪が背中（ブレザー）と同じ黒・同じレイヤーで、髪の外形線が背中の上に出ない。頭は「フード」か「おかっぱ」に見え、**「彼女＝長い髪のライン」というスタイルガイドの識別要件を満たしていない**。
- **直し方**: 髪を独立レイヤーにして、背中に重なる部分にも光側の内側リム（髪の外形線）を入れる。肩甲骨〜毛先で髪の輪郭が背中の輪郭からわずかにはみ出すようにし、毛先は束でまとめる。

### A3. 相合傘の傘が少年の頭にかぶさっている／黒傘はキノコ
- 傘の縁が少年の目の高さにあり、頭が傘の中に突っ込んでいる。透明傘では頭が膜を突き抜けているように見え、黒い傘では頭と傘が一体化して「平たいキノコ」になる。
- 傘の下側（縁の手前半分の楕円＝スカート部）が独立した平たい楕円に見え、UFO／クラゲ型。
- **直し方**: 柄を長く（握り→石突き 3.5u）、縁が頭頂より上に来るように。ドームを丸く高く、縁はスカラップの一本線に。石突き・柄・持ち手を見せる。

### A4. 抱擁が「抱き合っている」と読めない
- 彼の手前の腕が彼女の頭〜背中の上でループを描き、内側リム線が**ハート形の謎の輪郭**になっている。飛び込んだ瞬間（progress 0）は彼女の髪の後れ毛が彼の胸の上に白いひっかき傷のような線として散る。
- progress 0 でも彼女の両足が地面付近にあり「飛び込み」に見えない。彼は脚が一本の柱に融合した棒立ち。
- **直し方**: 構図を作り直す。彼女は彼の胸に頬をうずめ（顔は見せない）、彼は頭を垂れて彼女の髪に頬を寄せる。彼の手前の腕は彼女の背中を斜めに横切る一本のきれいな形、手は背中に。彼女の手前の腕は彼の脇の下から背中へ回り、**彼の背中の輪郭の外に指先が出る**（シルエットで抱擁と分かる一番のサイン）。0 は空中で両脚を後ろへ曲げ、髪が慣性で前へ、1 で爪先立ち＋片脚の跳ね上げ。

### A5. 膝立ちギタリストの頭が肩の後ろに落ちている（首が折れて見える）
- `headTilt -0.75` と `lean -0.32` の組み合わせで頭の中心が首の軸より後ろにずれ、頭が背中に貼り付いた「ロリポップ」。胴は肋骨のように細く、首は異様に長い。天を仰ぐ劇的なポーズのはずが、事故のように見える。
- **直し方**: 背中を反らす量を胴で受け、首は短く太く、頭は首の上で顎を上げる（後頭部が肩甲骨に触れない）。胸に厚みを。

## B. 重大（アニメの作画として美しくない／スタイルガイド不一致）

### B1. 髪のハイライトが等間隔の平行線（「すだれ」「バーコード」）
- 「上の層の毛束の縁に毛筋のハイライト」は、毛束の1/3に機械的に内側リムを付けているため、頭頂から毛先まで等間隔・等幅の白線が並ぶ。`dev_figures_2`（ピアノ）`10`（髪の単体）で顕著。アニメの黒髪の艶（天使の輪、房の重なりに沿って途切れる艶）とはまったく違う。
- **直し方**: 毛筋は数本〜十本を房ごとに偏らせ、長さ・開始位置・太さをばらつかせ、根元と毛先で消えるテーパー線に。頭頂の少し下に光源側だけの「天使の輪」（途切れ途切れの弧）を入れる。

### B2. 頭頂が二段に盛り上がる（後ろ姿の髪の付け根）
- 頭の丸み（cap）と毛束の付け根がずれて、頭頂にこぶ状の段ができる。ヘルメットか帽子に見える。
- **直し方**: 毛束の付け根を cap の輪郭線上（つむじ〜分け目）に置き、cap の外形を毛束の外形と連続させる。

### B3. 横向きの長い髪が「頭頂から出るポニーテール」
- 横顔の髪（走る・病室・髪の単体）は根元が後頭部の上の方に集中し、風で一本の帯にまとまるため、高い位置で結んだポニーテールに見える。設定は「腰まであるまっすぐな長い黒髪」。
- **直し方**: 根元を頭頂〜襟足まで後頭部全体に分布させ、上の束ほど水平に、下の束ほど下へ流れる扇形に。後頭部には髪のボリューム。

### B4. 強風の髪が「ほうき」／「濡れた麺」
- 風速 1.5 以上で毛束が全部細く分かれ、毛先がすべて鋭く尖る。束としての量感がなく貧相（嵐の橋、髪の単体の強風）。
- **直し方**: 房の中の毛束の位相・ノイズをそろえて「大きな房が数本」流れる形に。風で細くする処理をやめ、毛先は房ごとに炎のようにまとめる。後れ毛は少数・短め。

### B5. 少年の髪が坊主頭／ヘルメット（横顔すべて）
- 「少し長めの無造作な黒髪」のはずが、横顔では滑らかなキャップ。ジュース・ギター・手を伸ばす・抱擁・膝立ちすべてで頭が禿げて見える。
- **直し方**: 前髪が額〜目を覆う（顔の演技を隠す役目も兼ねる）、頭頂と後頭部に尖った房、襟足が首にかかる、もみあげ。風で房先が流れる。

### B6. 少年の首が長い／肩が「ハンガー」
- 後ろ姿で頭が細い首の上に浮き、襟と頭の間に長い首（ベンチ・相合傘）。肩は水平で角張り、腕が肩の外側から垂れ下がる「コートハンガー」型（相合傘で顕著）。
- **直し方**: 首を短く・頭を下げ、襟足の髪で首を隠す。僧帽筋の傾斜を強め、三角筋の丸みで腕に自然につなぐ。

### B7. 走る少女の腕がボクサー／手がミトン
- 両前腕とも胸の前で水平、拳が大きなミトン。腕振りが前後に開かず、走りの推進力が出ない。
- **直し方**: 腕振りを脚と逆位相で大きく（後ろの腕は肘を引き前腕は下、前の腕は前上）。手は小さく軽く握った形に。

### B8. ベンチの二人：ベンチが体の「奥」にあるように見え、脚が竹馬
- 背もたれは本来二人の手前にあるが、人物と同じ黒なので体の上で消え、「ベンチの後ろに立っている」「こちらを向いて座っている」とも読める。座面の下から地面まで太い筒の脚が伸び、ベンチの後ろに脚をぶら下げているよう。
- イヤホンのY字がはっきりしない（耳のイヤホンが頭頂付近に見える）。
- **直し方**: ベンチを木の色味（わずかに明るいトーン）＋上辺の内側リムで「手前」と分かるように。座面の下の脚は奥にあるので細く短く、足は地面より上（遠近）。Y字の分岐を胸の高さに下げる。

### B9. 欄干の少女：ギプス／スリングが後ろ姿で全く見えない
- `cast:true` でも右肘のふくらみが黒い塊になるだけで、事故後だと読めない（嵐の橋の核心）。
- **直し方**: 背中を斜めに横切る白いスリングの帯（首の後ろ→右肘）と、右脇から覗く白いギプスの肘を、明るいトーンの別レイヤーで描く。

### B10. 病室：ポニーテール、シートベルト、枕
- 髪が頭頂から背もたれの中へ垂れる（背もたれを突き抜けている）。スリングの帯が胸の前に浮いた太い白帯でシートベルトに見える。毛布は角の丸い四角に凸凹を付けただけで、枕か寝袋。
- **直し方**: 髪は背中に沿って落ち、手前の肩に一房（顔を隠す）。スリングは前腕を包む三角巾の袋＋首へ回る細い帯。毛布は胸元の折り返し・膝の山・爪先の山・マットレスの横に垂れる裾。

### B11. 細い手足・小さい人物が灰色に白ける
- 広い減衰リム（wide falloff）と全周逆光（omni）の幅が画面ピクセル基準（`rimPx` は scale^0.6）なので、小さく描くほど相対的に太くなり、腕・脚の中まで光が回ってシルエットが灰色になる（`dev_figures_1` の一覧で全員グレー）。
- **直し方**: 広い減衰・全周逆光の幅を人物の大きさ（u 単位）に比例させる。鋭いリムは従来どおり最小 1.1px を確保。

## C. 中程度

- **C1. ピアノの少女のふくらはぎ**：椅子の下にまっすぐぶら下がり、子供が足をぶらぶらさせているよう。ペダルへ向かう脚は奥へ行くので、短く細く、足は床より上に。
- **C2. 手を伸ばす少年の服**：嵐の中なのにシャツが筒のまま。裾と袖が風にはためかない。
- **C3. グリップの拳が大きい**（膝立ち 'lift'、ギターのネックを握る手）。ミトン型。小さく、親指の切れ込みを。
- **C4. 芝生の草**が四角いマットのように切れている（両端が直線）。
- **C5. 相合傘の歩き**がほぼ棒立ち（walk 0.7 でも脚の交差がほとんど見えない）。

初回計測（ヘッドレス Chromium、10回の中央値、強制ラスタ込み）:

| 関数 | 条件 | 中央値 |

| hairLong | bust, scale 1.6 | **48.8ms** ✗ |
| girlAtRailing | cast, bridge, 1.2 | **54.6ms** ✗ |

| guitaristKneel | 1.2 | 39.2ms（ぎりぎり） |
| その他 | 1.1〜1.25 | 23〜34ms |

- 原因: 描画パイプラインの固定コスト（全解像度のバッファ処理 8回＋全レイヤーの再描画2回）が**外接矩形の面積に比例**するのに、外接矩形が大きすぎる（欄干は ±4.8u の手すり、ベッドは 8u の台を毎フレーム同じパイプラインで描く、髪は風で最大限広がる前提の固定矩形）。
- **直し方**: (1) 描画前に軽いバウンディングパス（パスの座標だけを計算する偽コンテキスト）で実際の外接矩形を求める。(2) 外形リムを全レイヤー再描画ではなくアルファから作る。(3) ハローは1/4解像度で作る。(4) 静的な大道具（病室のベッド、毛布、橋の欄干）は光の条件ごとにキャッシュ。

### 残る弱点（正直に）
- 手は小さなシルエット（開いた手のみ指が分かれる）。手のアップは hands.js へ。
- ピアノの「斜め後ろ」は2Dのずらし（`turn` ±0.5 まで）。
- 走り・歩きはその場足踏み（地面の流れはシーン側）。
- 後ろ姿の髪の毛先は、横からの強い光で scale 1.3 以上だと毛先ごとの細い線がやや賑やか。
- キャッシュする大道具は `light`/`backlight` を毎フレーム動かすと描き直し（ベッド +60ms、欄干 +30ms）。
- 大写しは1体 40ms 前後。
