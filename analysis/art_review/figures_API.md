## 1. 共通仕様

### 座標系・スケール
- すべて `PV.lib.xxx(ctx, t, o)`。`o.x, o.y` が**アンカー**（関数ごとに「足元」「座面」などを明記）。
- 単位は「頭身 u」。**1u = 92px × o.scale**。先輩（ヒロイン）は 7.2u（scale 1 で約 660px）、主人公は 7.8u（約 720px）。
- ctx の現在の変形（`PV.camera` のズーム・回転など）はそのまま反映される。描画前に**バウンディングパス**（パス座標だけを計算する軽い偽コンテキスト）で実際の外接矩形を測り、その範囲だけをオフスクリーンで処理するので、拡大しても解像度は落ちず、画面外は描かない。
- 決定論的（`Math.random` 不使用）。ctx の状態は save/restore で元に戻る。呼び出し側の `globalAlpha` は合成時に尊重される。

### 共通オプション（全人物関数）
| キー | 既定 | 説明 |
|---|---|---|
| `scale` | 1 | 上記の u スケール |
| `flip` | false | 左右反転（横向きの人物は既定で右向き）。光の向き `light` は画面基準のまま |
| `style` | `'silhouette'` | `'silhouette'`＝ほぼ黒 `#0c1019` ＋光源側リム。`'soft'`＝暗いスレート `#273042` ＋ごく淡い方向グラデ（明るい室内・病室） |
| `light` | −2.2 | **人物から光源へ向かう方向**（ラジアン、画面座標）。0=右、−π/2=真上、π=左 |
| `rimColor` | `#ffe6c0`（soft は `#fff0da`） | リム色。**hex で指定**（髪の艶・傘の縁・イヤホンの色もこれから作る） |
| `rim` | 1 | リムの強さ（0 で無効、2 まで） |
| `rimWidth` | 1 | 鋭いリム幅の倍率（既定 1080p で約 2〜4px、画面上の大きさに応じて自動） |
| `backlight` | 0.2（soft 0.15） | 全周のやわらかい逆光（強い窓光・雷光のとき 0.4〜0.9） |
| `glow` | 0.55（soft 0.18） | 縁の外側のにじみ（ハロー） |
| `fill` | — | 本体色を直接指定 |
| `alpha` | 1 | 不透明度（フェード用） |
| `fps` | 12 | ポーズ・髪の更新レート。**12＝アニメの「2コマ打ち」**。0 で毎フレーム連続 |
| `seed` | 関数ごと | 髪のゆらぎ等の乱数種 |
| `wind`, `windDir` | 関数ごと | 風の強さ（0〜2）と**風が吹いていく方向**（ラジアン） |

### 光の作り方（パイプライン）
1. 各レイヤー（奥の手足・体・髪・小物）を平塗りで重ねる。重なりの見分けが必要なレイヤーだけ `inner`（そのレイヤー自身の光源側の縁に細いリム）を持つ。**内側の線は「相手の体を横切る前腕」「背中に重なる髪の縁」など、読ませたい所だけ**に限定している（上腕・肩まで線を入れると輪郭線が絡んで謎の形になるため）。
2. **外形のアルファだけ**から光を作る：鋭いリム（光源側 2〜4px）＋1/4解像度の広い減衰＋全周逆光＋外側ハロー。広い減衰と全周逆光の幅は**u 単位（人物の大きさに比例）**なので、小さく描いても手足の中まで光が回って灰色になることはない。
3. 最終画面ではエンジンのブルーム・グレイン・周辺減光が乗る。

**髪の艶**：黒髪には房ごとに偏った数本の毛筋（根元と毛先で消える細い線）と、光源側の頭頂の少し下に途切れ途切れの「天使の輪」が入る。強さは光とスタイルに連動（`soft` では控えめ）。

**静的な大道具のキャッシュ**：病室のベッド・毛布、`girlAtRailing` の手すりは、光の条件（`light`・`backlight` 等、0.03rad／0.05 刻みに量子化）×スケール×画面ズーム（2^(1/4) 刻み）ごとに一度だけ同じ光処理で描き、以後は貼るだけ（LRU 12件）。**`light` / `backlight` を毎フレーム大きく動かすと、その都度描き直しになる**（ベッドで +60ms 程度）。雷の数フレームは問題ないが、ゆっくり動かすなら段階的に。

`PV.lib.figureRender(ctx, o, bbox, paint)` を公開（`bbox` は互換のため受け付けるが不要）。`paint(F)` の中で `F.layer({fill|tone|toward|inner}, (c)=>{...})`（u 単位の平塗り）、`F.raw((c)=>{...})`（色を自分で指定する自由描画。シルエット内に収めるなら `source-atop`）、`F.tone(k, toward)`（本体色を k だけ toward 色へ）、`F.rimCol`、`F.fill` が使える。**paint は外接矩形の計測のために1回呼ばれ、記録されたレイヤーが本描画で再生される**（paint 内で `F.T` を保持しないこと）。

## 2. 関数リファレンス

### `PV.lib.hairLong(ctx, t, o)` — ヒロインの長い黒髪
毛束（既定20本、5つの「房」）＋後れ毛（既定5本）。**毛束は頭頂（つむじ）から頭の丸みに沿って流れ**（後ろ姿は頭の楕円の経線、横向きは頭頂〜襟足の弧）、襟足・こめかみで頭を離れてから重力・肩での広がり・風・揺れの遅れで落ちる。頭頂は一つのなめらかなドーム。房ごとに波の位相と向きを共有するので、強風でも「大きな房が数本」流れる（細い毛がばらばらに散る「ほうき」にならない）。横向きは根元が後頭部全体に分布し、風が強いほど上の毛束が早く頭を離れて扇形に流れる（ポニーテールにならない）。
- アンカー: `o.x, o.y` ＝**頭の中心**。
- `view`: `'back'`（後ろ姿）／`'side'`（右向き横顔：後頭部から背中へ）
- `len` 2.7（頭の中心→毛先、u。2.7≒腰）、`wind` 0〜2、`windDir`、`tilt`（頭の傾き）、`swing`（動きの遅れ）、`count`、`wisps`、`mess`、`spread` 0.05（肩での広がり）、`droop`、`thick`、`clumps`
- `style` を指定すると人物と同じ光で描く（髪の縁の内側リム＋艶）。未指定なら `o.color` の平塗り（艶なし）。
- `bust: true` で頭・首・肩の胸像（なで肩、下端は丸い彫刻の台座型）を添える。
- 推奨: scale 1.2〜2.5。例: `L.hairLong(ctx,t,{x:960,y:330,scale:1.6,style:'silhouette',view:'side',wind:1.5,windDir:Math.PI-0.15,bust:true,light:-2.1})`

### `PV.lib.girlAtPianoBack(ctx, t, o)` — ピアノに向かう少女の後ろ姿（やや斜め後ろ）
ピアノ椅子に座り鍵盤へ向かう。`intensity` で〈雪あらし〉級の激しさ：体の左右の揺れ・前への突っ込み・肩の緊張・頭の振り、髪は揺れに遅れて振られる。右手は高音域へ伸びて体の脇から見える。**ペダルへ向かうふくらはぎは椅子より奥なので、細く・わずかに霞んだトーンで・足は床より上**に描く。
- アンカー: **ピアノ椅子の座面中央**。頭頂は y−4.6u、椅子の脚は y+2.1u（床）。
- `intensity` 0〜1（既定 0.3）、`turn` −0.5〜0.5（既定 0.35＝右肩越しの斜め後ろ。0 で真後ろ。2D のずらしなので ±0.5 まで）、`bench` true、`outfit` `'blouse'`|`'blazer'`、`hairLen` 2.5、`wind`
- ピアノ本体は描かない（instruments.js）。鍵盤の高さはアンカーの約 1.3u 上。
- 推奨: scale 1.0〜1.6、窓の逆光（`light` −1.2 付近、`backlight` 0.3）。

### `PV.lib.boySeated(ctx, t, o)` — 椅子に座る少年（横向き・右向き）
学校の椅子付き。少年の髪は「少し長めの無造作」：前髪が目にかかり、頭頂はふくらみ、後頭部は丸く、襟足に房（頭を傾けても房は下へ垂れる）。
- `pose: 'juice'`：背もたれに寄りかかり、顎を上げてパックジュースのストローを咥える。
- `pose: 'guitar'`：前屈みで俯き（前髪で目が隠れる）、アコギを膝に。ボディは客席側へ少し開いて見せる。左手はネックを握り、右手はサウンドホール上でストローク。
- アンカー: **椅子の座面中央**（床は y+2.0u）。`chair` true、`outfit` `'shirt'`|`'blazer'`|`'jacket'`、`guitarTone` 0.1、`soundhole` true、`wind`
- 推奨: scale 0.9〜1.4、窓際の逆光。

### `PV.lib.coupleSittingBack(ctx, t, o)` — 並んで座る二人の後ろ姿
左に先輩、右に主人公（`flip` で入れ替え）。**ベンチは二人の手前にあり、木のわずかに明るいトーン＋板の上辺のリムで「手前」と分かる**。座面の下に見える脚は奥にあるので細く霞ませ、足は地面より上。先輩の髪は独立レイヤーで、背中に重なる髪の縁に細い線が入る（後ろ姿でも長い髪だと分かる）。
- `lean` 0〜1：彼女の頭が彼の左肩に寄りかかる。
- `earphones: true`：**二人の頭の間に白いコードの V 字**（彼女の右耳と彼の左耳から肩の高さの分岐へ）、そこから1本が二人の体の隙間を下る（第二話のモチーフ）。彼女の頭が彼の耳を隠す姿勢では、彼の側のコードは彼女の頭の後ろを通る。
- アンカー: **二人の間の座面中央**（`seat:'grass'` なら地面）。
- `seat` `'bench'`|`'grass'`（芝生：彼は右手を後ろにつく、手前に不揃いな草の房）、`backrest` true、`boyOutfit`、`girlOutfit`、`wind`、`windDir`
- 推奨: scale 0.9〜1.8、青空・中庭（`light` −0.8、`backlight` 0.25）。

### `PV.lib.girlRunning(ctx, t, o)` — ドレスとヒールで走る少女（横から）
8キーポーズを Catmull-Rom で補間した走りのサイクル、2コマ打ち。**腕は脚と逆位相で前後に振る**（後ろの腕は肘を引いて前腕を下げ、前の腕は胸の前へ）、手は小さく軽く握る。ドレスは前脚の膝に押され後ろへたなびき、髪は後頭部全体から一枚の帯になって後ろへ流れる。
- アンカー: **彼女の真下の地面**。その場で走る（背景・カメラ側で流す。強く見ると接地がわずかに滑る）。
- `speed` 1.45、`phase`、`outfit` `'dress'`（ローヒール）|`'uniform'`、`hairLen`、`wind`
- 推奨: scale 0.8〜1.3、夜の臨海公園（`light` −0.25、`backlight` 0.35、琥珀の `rimColor`）。左へ走らせるときは `flip:true`。

### `PV.lib.embrace(ctx, t, o)` — 胸に飛び込む抱擁（横から）
彼女（左・右向き）が胸に飛び込み、彼（右・左向き）が抱きとめる。
- `progress` 0〜1：**0＝飛び込んだ瞬間**（彼女は空中で両膝を後ろへ曲げ、髪は慣性で後ろ上へ舞い、彼は少しのけぞって腕を回しはじめる）→ **1＝落ち着いた抱擁**（爪先立ち＋片足の跳ね上げ、彼は頭を垂れて彼女の髪に頬を寄せる）。`PV.smooth(0, 3, t)` などで動かす。
- 読ませ方：二人の体は抱擁の一つのシルエットに溶け合わせ、**彼の前腕が彼女の背中を横切って手が背中に**、**彼女の前腕が彼の胴を横切って指先が彼の背中の輪郭の外に出る**（抱擁だと一目で分かるサイン）。彼女の顔は彼の胸にうずめて見せない。彼の顔は彼女の頭に隠れ、後頭部は丸く襟足の房は下へ垂れる。
- アンカー: **二人の間の地面**。`outfit` `'dress'`|`'uniform'`、`boyOutfit` `'jacket'`|`'shirt'`|`'blazer'`、`wind`
- 推奨: scale 0.9〜2.1（`dev_figures_12` で 2.1 の大写しを確認済み：内側の線は2本の前腕と彼女の頭の縁だけ）、夜景の逆光。

### `PV.lib.guitaristKneel(ctx, t, o)` — スポットライトの中、膝をつき天を仰ぐ少年
両膝をつき、**背中を反らせ、顎を上げて天を仰ぐ**（頭は首の上に乗ったまま回転し、肩の後ろへ落ちない）。白いストラトキャスターは明るいトーン＋縁のハイライトで「白いギター」と分かる。
- アンカー: **膝の下の床**。
- `hold`: `'raise'`（ストラップで提げ、左手はネック、右手を高く空へ）|`'lift'`（両手でギターを頭上に掲げる）|`'chest'`（胸に抱く）
- `guitarTone` 0.32、`outfit`、`wind`。`light` 既定は真上（−π/2）。
- 推奨: scale 0.8〜1.3、暗い体育館＋スポット。

### `PV.lib.girlAtRailing(ctx, t, o)` — 欄干／窓辺に立つ少女の後ろ姿
片脚重心のコントラポスト。強風で髪が房ごと横へ流れ、プリーツスカートの風下側がめくれる。両手は前の手すりに置く（体の陰）。手すりは彼女の向こう側（キャッシュ描画）。
- **`cast: true`（事故後）**：右腕は肘を曲げて前へ。**背中を斜めに横切る白い三角巾の帯**（髪の下から右肘へ）と、**右肘を包む三角巾の尖った角**が明るいトーンで見える。`castTone` 0.62（帯の明るさ。暗い嵐では 0.5〜0.65、昼は 0.75 前後）。
- アンカー: **両足の間の地面**。
- `wind` 1.0、`windDir` 0、`windLift`、`railY` −4.5、`railing` true|false|`'bridge'`、`hands` `'rail'`|`'sides'`（下ろした手は後ろから見た細い手の形）、`handSpread`、`outfit` `'blazer'`|`'blouse'`、`weight`、`headTilt`、`hairLen`
- 推奨: scale 0.9〜1.8、嵐の橋（`railing:'bridge', railY:-4.9, wind:1.6, cast:true, rimColor:'#cfe0ff'`）。

### `PV.lib.boyReaching(ctx, t, o)` — 手を伸ばす少年（横向き・右向き）
片脚を踏み出し前傾、右腕を前へ伸ばし指を開く。伸ばしきると肩が上がり、指先がわずかに震える。**風が 0.25 を超えるとシャツの背中が風をはらみ（裾ほど大きく、2コマ打ちではためく）、伸ばした腕の袖もはためく**。前髪・襟足が風に流れる。
- アンカー: **彼の真下の地面**。`reach` 0〜1、`outfit` `'shirt'`|`'jacket'`（革ジャンははためかない）|`'blazer'`、`wind` 0.5、`windDir` π
- 推奨: scale 0.9〜1.3、嵐（`light` −1.0、雷のフレームで `backlight` を一瞬上げる）。

### `PV.lib.coupleUmbrella(ctx, t, o)` — 一本の傘に入る二人の後ろ姿（雨）
左に彼女、右に彼。**傘は二人の頭より上**（柄の長さ 3.6u、縁は彼の頭頂より約 0.3u 上）。**下から見上げた傘**として描く：丸いドームの外側、手前の縁（上側の弧、光る線）、その下に傘の内側（暗いレンズ形、骨が放射状に見える）、奥の縁はスカラップ状の下辺。傘は彼女の側へ傾き、**彼の右肩は縁の外で雫が落ちる**（原作どおり彼の右肩が濡れる）。彼女の右手は彼の袖をつまむ。
- `walk` 0〜1：歩いて遠ざかる。持ち上がる足は膝が曲がり踵が上がって高く見え、ズボンの脚の間に隙間が出る。
- `umbrella` `'dark'`（既定）|`'clear'`（ビニール傘：半透明の膜・外側の骨・内側の骨・両方の縁・水滴を合成後に重ね、柄は彼女の頭の後ろを通る）
- アンカー: **二人の間の地面**。`tilt` −0.2、`drips` true、`wind`、`windDir`
- 推奨: scale 0.8〜1.4、雨＋夕暮れの街（`light` −1.9、`backlight` 0.4、`rimColor:'#d6e2f6'`）。雨の筋はシーン側で `L.rain`。

### `PV.lib.girlInBed(ctx, t, o)` — 病室のベッドで上体を起こす少女
起こした背もたれに**もたれかかって**座り、顔は窓の方（画面奥）へ向ける＝**後頭部と長い髪だけが見え、髪が手前の肩に落ちて顔を隠す**。右腕（手前）は白いギプスで、**三角巾の袋が前腕の下に垂れ**、袋の先から指先が出る。細い吊り紐が胸の前を通って首の後ろ（髪の下）へ。**毛布**は腰の折り返し・膝の山・爪先の山を通ってマットレスの端まで覆い、手前の側面と足元に垂れる（ひだは垂れた部分だけ）。ゆっくり呼吸する。
- アンカー: **彼女の腰の下のマットレス上面**（ベッド全体は x −2.5〜+5.8u、床は y+2.5u）。
- 既定 `style:'soft'`。`bed` true、`headTurn` 1（推奨。1 未満は髪の下に顎の線が出る）、`castTone` 0.75、`sheetTone` 0.45、`wind`
- ベッドと毛布はキャッシュ（§1）。推奨: scale 1.0〜1.6、冷たい白の病室・窓の逆光（`light` −0.45、`rimColor:'#ffffff'`）。

## 4. 既知の弱点（使う側の注意）
- **手**は小さなシルエット。指が分かれるのは開いた手（`boyReaching`、抱擁で相手の背中に置く手、`'raise'` の手）だけ。手のアップは hands.js を使うこと。
- **ピアノの「斜め後ろ」**は肩と腕のずらしによる2D的な見せ方で、体は回転しない（`turn` は ±0.5 まで）。
- **走り・歩き**はその場での足踏み。地面の流れはシーン側で付ける。強く見ると接地がわずかに滑る。
- **後ろ姿の髪の毛先**は、横からの強い光では毛先ごとに細い内側の線が入り、scale 1.3 以上ではやや賑やかに見える（相合傘・ピアノ）。
- **静的な大道具のキャッシュ**は光の条件ごとに作り直すため、`light`/`backlight` を毎フレーム動かし続けるとベッドで +60ms、手すりで +30ms 程度かかる。
- 大写し（画面いっぱい）では1体 40ms 前後になる。
