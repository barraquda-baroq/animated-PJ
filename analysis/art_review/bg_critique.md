# 背景美術ライブラリ 講評と修正記録（美術監督）

対象: `pv/engine/lib/atmos.js`（PV.lib 背景美術）とショーケース `pv/scenes/_dev_bg.js`（dev_bg_1〜8）
確認画像: `analysis/art_review/bg_review/`（r0 = 受け取り時点、r1a/r1/r2/r3 = 修正の各往復、final = 最終）

## 0. 受け取り時点の講評（r0）

担当者の報告どおり、8 シーンはエラーなく描け、関数は 40ms 以内に収まっていた。だが**劇場アニメの背景美術としては、まだ「CG の素材集」**だった。以下、重い順に。

### A. 雲 ― いちばん目立つ欠点
- **3D の粘土／マシュマロに見える。** 球の集合をそのまま滑らかに陰影付けしているため、もこもこの一つひとつが「ボール」に見える（`bg_review/r0/dev_bg_1_4.00.jpg` 中央、`dev_bg_2` の入道雲）。
- **中間調が多く、色が濁る。** 影色が灰色がかったラベンダー（spring shadow `#aeb4db`）で、雲全体が「薄紫の灰色」に沈む。スタイルガイドの「白〜#a9bde0 の影」（澄んだ青い影）になっていない。
- **入道雲が白飛びの塊。** 光の側に形がなく、影の側は低コントラストのぼかし。頂部は画面上端で切れている。
- **逆光の雲が「ドクロ」に。** 太陽に近い雲（lightZ < 0）で、手前を向いた球の縁だけが光り、輪っかが並んだ（`bg_review/r0` の右下の雲）。
- **互換性の劣化**: 旧 API の暗色指定 `colors:{lit:'#5a6b8f',...}`（dev_storm・dev_figures の嵐）で、ハイライトが lit の 40% 白寄せ、リムが純白になり、**嵐の雲が月夜の積雲のように明るく**なった（`bg_review/r0_compat/dev_storm_1.00.jpg`）。
- **旧レイアウトの崩れ**: `L.clouds` の折り返し幅を `W + maxW + 400` に変えたため、雲が画面外にいる時間が増え、他エージェントの空（dev_sky など）で**見える雲の数が平均 3 割減**っていた。

### B. 空のディテール
- **巻雲が「引っかき傷」。** `pow(ridge,3)` の細線で、空に傷が入ったように見える（`r0/dev_bg_1` 右上）。
- **うろこ雲が水玉模様。** 陰影のない白い楕円の点描で、雲ではなく「窓ガラスの水滴」か「水玉」に見える（`r0/dev_bg_5`）。

### C. 水面
- **海が一様な横線ノイズ。** 細いストロークが均等に敷き詰められ、ヘアライン加工の金属板のよう。波の列・風の当たる面と凪の面のリズムがない。
- **光の道が弱い。** 太陽の下のきらめきが、数個の「四芒星シール」が縦に並ぶだけ（`r0/dev_bg_2` 左、`r0/dev_bg_8`）。
- **近景の白波がない**（担当者自身も弱点に挙げていた）。
- **夜の水面が明るく、走査線状。** 地の横筋が明るすぎ、映り込みと区別がつかない。
- **雨の着水が「笑顔の記号」。** 上半分の弧＋2本のヒゲで、海面に小さな ^‿^ が並ぶ（`r0/dev_bg_4`）。

### D. 嵐（クライマックスの〈テンペスト〉）
- **暗雲が煙。** |noise| の fbm がマーブル状の筋になり、塊の重さがない。雷光で照らしても「煙が光った」だけ（`r0/dev_bg_4_0.00.jpg` / `4.00`）。

### E. 夜景・構造物
- **夜景が箱の列。** 窓がまばらな直方体が並ぶだけで、横スクロールゲームの背景のよう。遠景の光の絨毯（街灯の帯）、ランドマークがない。臨海公園（原作の重要な場所）なのに観覧車がない。
- **夜景キャッシュが y を含む。** `L.skyline` は y を変えるたびに 1920 幅のキャンバスを作り直す。カメラのティルトやパララックスで y を動かすと、**毎フレーム 40ms＋数 MB のリーク**になる。
- **海の下地キャッシュが水平線の位置を含む。** 同じく、`horizonY` を動かすと毎フレーム作り直し（65ms＋メモリ増）。
- **夜の水面の映り込みが灯りの位置ごとにキャッシュ。** 夜景を横にパンすると毎フレーム作り直し。
- **大橋が細い。** 桁が 1 本の線で、白い桁が白い霞に溶ける。主塔は棒。
- **月の地球照が強すぎる。** 三日月の暗部が灰色の円盤として見え、「惑星」に見える。

### F. 植物・木漏れ日
- **木漏れ日が紙吹雪。** 同じ大きさ・同じ色の丸い斑が地面にも壁にも均一に散り、光ではなく「ボケ玉」か「雪」に見える。日向と日陰のコントラストもない（`r0/dev_bg_6`）。
- **葉がクリップアート。** 葉の形が 1 種類で、近いと切り絵に見える。
- **天蓋（canopy）が重い。** 葉を毎フレーム 1 枚ずつ描くので 25ms。木漏れ日 2 枚と合わせると、中庭カット全体で 92ms/フレーム（目安 80ms 超え）。

### G. 色彩
- **夕焼けがマゼンタに寄りすぎ。** グラデーションツールそのままの紫→ピンク→橙の帯。

## 1. 修正方針

| 問題 | 修正 |
|---|---|
| 雲の CG 感 | `paintCloud` に**塗りのランプ**を追加。陰・半陰・光の 3 つの面を、筆でゆらいだ細い境界で塗り分ける。各もこもこの影側が「三日月形の影」、谷が「スカラップの線」になり、光の面は静かに保たれる。形の陰影は従来の高さ場・法線場をそのまま使う |
| 影色の濁り | 雲パレットを全面改訂。光は白〜わずかに暖色、影は空を映した澄んだ青（#a9bce2 前後）、谷は群青。`sky` 色を追加し、影側の輪郭は空の色を帯びて薄くなる（空気に溶ける） |
| 逆光の輪っか | 逆光時は大きな形の法線を優先し、さらに「厚み」（被覆の広いぼかし）で内部の直射を消す。光るのは薄い縁だけ（銀の縁取り） |
| 暗色レガシー | 指定色の明度から hi/rim/sky を導出（暗い lit なら hi は +10% だけ、rim は lit 寄り）。嵐の雲は嵐の色のまま |
| 雲レイアウト | `L.clouds` の折り返しを旧ライブラリと同一式（`W + w + 200`、`-w - 100`）に戻した。乱数の消費順も旧と同じなので、旧呼び出しは元の配置になる |
| 巻雲 | 「細長い斑」×「櫛でといた繊維」の密度場に変更。刷毛でかすれた羽毛状の筋になる |
| うろこ雲 | 雲片を 1 つずつ小さな積雲として塗る（日の当たる上面＋青灰の下面、ゆらいだ縁、遠いほど小さく霞む）。波打つ列に並べる。`morph` で 2 状態のクロスフェードによるゆっくりした変形も可能 |
| 海 | 下地を「描いた波」に変更。暗い谷のレンズ形＋空を映す明るい縁、風の当たる面と凪の面の低周波マスク、水平線近くの細い反射。光の道は数千の横きらめきを 2 層に分け、行ごとに瞬かせる。近景に白波（巻いた白い唇＋泡）。海の下地は**規定の高さで一度だけ描き、任意の水平線・高さに写像**する（ティルトしても再描画なし） |
| 夜の水面 | 下地を暗く。映り込みを**灯りごとのキャッシュ柱**にし、毎フレーム並べ直す（パンしても再描画なし）。`dx` で全灯を移動できる |
| 嵐 | 暗雲を作り直した。遠くの霞んだ天井（ノイズ）＋その下に並ぶ**嵐のセル**。セルは積雲と同じ画家で塗るので、重いカリフラワーの塊になる。雷光版はまったく同じ形の別スプライトで、閃光点の周囲だけクロスフェードする。天井の下端を上から重ね、セルが天井の下から湧き出して見えるようにした |
| 夜景 | セットバック・斜めの頂部・ファサードの陰影・頂部の照明帯・全点灯のタワー・遠景の光の絨毯を追加。キャッシュから y を外し（パララックス無料）、件数上限 24 の LRU にした |
| 観覧車 | `L.ferrisWheel` を新設。昼は白い鉄骨、夜は電飾（ゆっくり流れる虹色／暖色／寒色のパターン）。夜の水面用に灯りを返す |
| 大橋 | 主塔を太くテーパー付きにした。桁は上面ハイライト・下面の濃い影・下縁の線で白い霞から分離する。H 型は脚の間の暗い隙間を描く。逆 Y 字の主塔 `style:'Y'` を追加 |
| 月 | 地球照の既定値を 0.12 から 0.05 に下げ、色を空寄りにした |
| 着水 | 遠近で大きさが変わる細いリング＋最初の一瞬だけ立つ小さな水柱に変更 |
| 木漏れ日 | 模様を作り直した。梢の隙間＝楕円の重なり、それを葉の形にかじった穴を開けた不規則な日向、周囲にピンホールの小斑。暖色を強め、日陰を濃く。余分な丸斑を減らした |
| 葉 | 卵形・披針形・丸形の 3 形状と葉脈。`blur` はバッファに描いてから 1 回だけぼかす（葉ごとのフィルタは遅い） |
| 天蓋 | 葉房をテンプレート（層×明るさ×8 種）として一度だけ塗り、各房は拡大して貼るだけにした（25ms → 数 ms） |
| 夕焼け | グラデーションを群青→藍→藤→くすんだ薔薇→橙→金へ改訂。マゼンタの帯をなくした |

## 2. 往復記録

### r1a（ライブラリ第 1 弾の直後） `bg_review/r1a/`
- 雲: 1・2・8 の雲がアニメ背景の塗りになった。入道雲は光の面と青い影の面がくっきり分かれ、もこもこが三日月の影で読める。
