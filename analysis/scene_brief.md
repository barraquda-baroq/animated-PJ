# カット制作ブリーフ（演出・作画エージェント向け）

あなたは劇場アニメ『キミの右手のアイロニー』本予告（3分）の、担当カットの演出・作画・撮影を一人で担う。

## 必読
- 絵コンテ（人間向け）: /home/user/animated-PJ/analysis/pv_storyboard.md （全体の流れ・前後のカットを把握する）
- 絵コンテ（データ）: /home/user/animated-PJ/pv/storyboard.json
- 美術・作画スタイルガイド: /home/user/animated-PJ/analysis/art_style_guide.md
- エンジン: /home/user/animated-PJ/pv/engine/core.js（PV.shot / PV.rng / PV.noise2 / PV.ease / PV.smooth / PV.window / PV.camera / PV.cached / PV.buffer など）
- 共通ライブラリ（PV.lib.*）: /home/user/animated-PJ/pv/engine/lib/*.js と、その API 説明 /home/user/animated-PJ/analysis/art_review/*_API.md
  - atmos.js（空・雲・光芒・塵・ボケ・雨・雷・花びら・海・橋・夜景・星・音符の嵐）
  - fx.js（雨の窓ガラス、光漏れ、真っ白な世界、カメラシェイク、ピント送り、光の掃き、心電図ライン）
  - hands.js（手のリグ：鍵盤の右手、フレットの左手、指先が触れる、指を絡める、ギプス、ハンカチ）
  - figures.js（人物シルエット：ピアノの後ろ姿、座る少年、並んで座る二人、走る少女、抱擁、膝をつくギタリスト、欄干の少女、傘の二人、病室のベッド）
  - instruments.js（グランドピアノ、鍵盤アップ、ギター、白いストラト、指板と弦の振動・切断、アンプの赤ランプ、楽譜の消失、音楽室、窓とカーテン、コンクールの舞台、体育館ステージ）
  - props.js（弁当、パックジュース、イヤホン、スマホ画面、ハンドクリーム、ネックレス、ハンカチ、傘、心電図、点滴、リンゴ類、耳栓、鍵、左手で書いた名前のノート、中庭のベンチ）
  ※ライブラリは他のエージェントが並行して改良中。API説明にある関数を使い、無ければ自分のシーンファイル内に描画コードを書く（ライブラリファイルは編集しない）。

## 作るもの
- /home/user/animated-PJ/pv/scenes/<担当グループID>.js に、担当カットそれぞれを `PV.shot('<カットID>', { draw(ctx, t, d, S) { ... } })` で登録する。
  - t はカット開始からの秒（トランジションで前後に少しはみ出すことがあるので t<0 や t>d でも破綻しないように clamp する）。d はカットの尺。S.params に任意のパラメータ。
  - 画面は 1920x1080。ctx は毎フレーム黒でクリア済み。save/restore を守る。
  - 決定論的に描く（Math.random / Date 禁止）。重い静的部分は PV.cached でキャッシュ。1フレームの描画は目安 80ms 以内（still.cjs が ms を表示）。
- カメラワーク（ゆっくりした押し引き・パン・パララックス）と、光・粒子・髪や布の揺れなど「止め絵に見えない生気」を必ず入れる。アニメの撮影処理（被写界深度のぼかし、逆光のフレア、空気遠近）を意識する。
- テロップ（モノローグ縦書き・字幕・コピー・タイトル）はエンジンがDOMで上に重ねる。絵コンテのテロップ位置（縦書きは画面右側 x≈1500〜1760、字幕は画面下 y≈950〜1030、中央コピー）に重要な被写体を置かない／暗めにして読めるようにする。
- 絵コンテの意図（何を感じさせるカットか）を最優先し、制約上描けないものは、別の構図・象徴で同じ感情を表現する（顔の演技は描かない）。

## 確認の仕方
```
cd /home/user/animated-PJ && node tools/build_index.cjs
node render/still.cjs --solo <カットID> --times 0.1,<中間>,<終わり-0.1> --out /home/user/animated-PJ/analysis/scene_review/<カットID> --sheet
```
- 出力された JPEG を Read で必ず目で見る。PAGE ERRORS が出たら直す。
- 1カットにつき「描いて→見て→直す」を最低3回。動きは複数時刻のスチルで確認する。
- 前後のカットとのつながり（色・光・画面の向き・動きの方向）も意識する。

## 品質基準
- 劇場アニメの予告編として恥ずかしくない画。光と色が美しく、構図に意図があり、一目で何の場面か分かる。
- 人体（特に手）の破綻がないこと。シルエットで二人が見分けられること（彼女＝長い黒髪、彼＝ギター／肩幅）。
