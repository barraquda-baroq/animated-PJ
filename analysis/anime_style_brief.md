## 1. なぜ描き直すのか
原作者（依頼主）から、完成版を見たうえでの指摘：
> 「30年くらい前のポリゴンっぽいキャラデザですね。もっとアニメ調というかそういう感じは難しいですか」

現状の人物は、(a) 顔のないマネキン／平板な影絵シルエット、(b) C16/C17 のように 3D 投影した面で組んだ人体で、
1990年代のポリゴンCGに見える。背景美術・手のアップ・テロップは劇場アニメの水準にあるので、**人物だけが浮いている**。

→ 人物を、日本の劇場／TVアニメ（京都アニメーション、CloverWorks、新海誠作品の人物作画）のような
**「線画＋セル塗り＋艶のある瞳と髪」**のキャラクターに描き直す。**顔を見せる方針に転換する**
（旧スタイルガイドの「顔の演技を見せない」は撤回。泣き顔・叫び・微笑み・空虚な目で語る）。

## 2. 目指す絵（ポリゴンに見えないための具体的な約束）
1. **主線**：入り抜きのある線（`PV.anime.taper`）。外形線は太め、内側の線（服のしわ・髪の房の分け目・鼻・口）は細め。
   色は黒ではなく素材ごとの濃い色（肌＝暖かい茶、髪＝黒紫、白い服＝青灰）。線幅は画面上の頭の高さに比例（`PV.anime.inkW(headPx)`）。
2. **塗り**：ベタ（base）＋1影（shade、境界はくっきり）＋必要な所だけ2影（deep：首の下、髪の内側、脇）＋ハイライト（hi）。
   影の形は**光源から決まる「アニメの影の形」**（顔なら髪の落ち影、首の影、頬骨の下の小さな影）。
   **立体を面ごとに塗り分ける（ファセット状の陰影）、全身にかかる3D的なグラデーション、硬いローポリの角は絶対に禁止**——これがポリゴンに見える最大の原因。
   グラデーションを使ってよいのは「髪の上下の淡いグラデ」「頬の赤み」「瞳」「光源側から薄くかかる空気・色のオーバーレイ」だけ。
3. **瞳（最重要）**：太い上まぶたのライン（目尻に向けて太く、睫毛の束が跳ねる）、短く細い下まぶたの線、
   縦長の虹彩（上端は上まぶたの落ち影で暗く、下に向けて明るいグラデ）、瞳孔、白いハイライト（大きい楕円1＋小さい点1〜2）、虹彩の縁取り、
   白目は少し青みのある白で上側に影。左右の目は同じ大きさ（3/4では奥の目を細く）。
4. **顔**：細い顎、頬のふくらみ、鼻は小さな影か短い線（3/4では鼻筋の線と鼻先の小さな影）、口は小さな線（話す・叫ぶ時に開き、口内は暗い赤＋舌の淡い色）。
   頬の赤み（ぼかした楕円＋短い斜線）。横顔は「額→目のくぼみ→小さな鼻先→人中→唇→顎→顎のライン」の美しいS字。
5. **髪**：頭蓋より大きなボリューム。房（束）の集まりとして描き、毛先は尖る。前髪は房の重なり（先輩はシースルーで額が覗く）。
   房の付け根側に影、内側の髪はdeep。**天使の輪**（頭頂のやや下を回るギザギザ縁のハイライト帯）。風・動きで房ごとに揺れる。
6. **体**：頭身（先輩7.0、彼7.3）。首は細い。肩幅は先輩≒1.45頭、彼≒1.8頭。脚は長め。手は画面上で小さい時は簡略（指の分かれを線で）。
   服のしわは少数の線と影の形で（多すぎない）。プリーツスカートは折り目の線と影の交互。
7. **光**：シーンごとの照明（`PV.anime.LIGHT` の名前）で色を変える（`PV.anime.mat(material, light)`）。
   逆光ショットは本体を暗い色に沈め、外形の光源側に鋭いリムライト（セルの帯）。**夜や嵐でも線と色を残す**（真っ黒の影絵にしない）。

## 3. キャラクター設定
`pv/engine/lib/anime.js` の `PV.anime.DESIGN` と `PV.anime.COLORS` が正。要点：
- **先輩**（ヒロイン、高3、18歳、ピアニスト）：周りが騒ぐほどの美人。長い青みの黒髪（腰近くまでのストレート、シースルー前髪は眉の高さで少し右分け、顔の横に胸まで届く長い触角）。
  切れ長でやや目尻の上がった大人っぽい目、長い睫毛、紫がかったグレーの瞳。細身。張り詰めた努力家で、普段は無表情に見えるが、笑うと素直で無垢。
  衣装：白ブラウス＋三年の赤いリボン＋紺のプリーツスカート／紺ブレザー（春）／コンクールの濃紺のドレス（髪をアップ＝低いシニヨン、細いチェーンのネックレス、低いヒール）／
  夜の公園はドレス＋淡いグレーのカーディガン（シニヨンがほどけかけ）／夏の白いワンピース＋つばの広い白い帽子（紺のリボン）／事故後は病院のパジャマ・右腕に白いギプスと吊り帯。
- **彼**（主人公、高2、17歳、ギタリスト）：背が高く細身。少し長めの無造作な黒髪、前髪が目にかかる尖った房、襟足が跳ねる。
  眠そうな細い目（集中すると鋭くなる）、睫毛は少なめ、まっすぐな眉、焦げ茶の瞳。飄々として軽いが、内側は乾いて孤独。照れると鼻の頭を掻く。
  衣装：白シャツ（袖まくり）、緩めた紺のネクタイ、チャコールのズボン／紺ブレザー／夜は着古した焦げ茶の革ジャン＋黒T／嵐の夜は雨で張りつく白シャツ。
  ギター：塗装の剥げた白いストラトキャスター（母の形見）、音楽室の傷だらけのアコースティック。
- **叔母**：40歳前後。肩までの黒髪を低く結ぶ、長い暗色のコート、表情のない顔と見透かすような視線（登場は C36 の戸口の逆光の立ち姿のみ）。

## 4. 技術ルール
- エンジン：`pv/engine/core.js`（`PV.rng`, `PV.rand1`, `PV.noise2`, `PV.cached`, `PV.buffer`, `PV.makeCanvas`, `PV.linGrad`, `PV.radGrad` など）。共通キット：`pv/engine/lib/anime.js`（読むこと）。
- 決定論的に描く（`Math.random` / `Date` 禁止）。時間で動くもの（瞬き・髪の揺れ・口パク）はすべて引数の時刻から計算する。
  アニメらしさのため、髪・体の揺れの更新は「2コマ打ち」（`PV.anime.onTwos(T)` で12fpsに量子化）。カメラの動きは24fpsのまま。
- 性能：頭1つ ≦ 15ms、全身1人 ≦ 30ms（1920×1080、`render/still.cjs` が描画msを表示）。重い静的部品は `PV.cached` や `PV.buffer`。
- 確認：`cd /home/user/animated-PJ && node tools/build_index.cjs` → `node render/still.cjs --dev <shotId> --dur 6 --times 0,2,4 --out <dir> --sheet`。
  **出力されたJPEGを Read ツールで必ず目で見る**。「描く→レンダリング→見る→直す」を何度も回し、プロのアニメーターが見ても破綻のない美しい絵になるまで磨く。
  細部はクロップして拡大して確認する（例：python3 + PIL で顔だけ切り出して2倍に拡大）。
- ポストエフェクト（ブルーム・グレイン・周辺減光）は still でもかかる。最終画面と同じ見え方で判断できる。
- 担当ファイル以外は編集しない（他のエージェントが並行作業している）。`pv/engine/lib/anime.js`（共通キット）に関数を足したい場合は、
  既存の関数の意味を変えない「追加」だけにし、最終報告に書くこと。

## 5. 合格基準（批評・レビューはこれで判定する）
1. 一目で**日本のアニメのキャラクター**と分かる（3D・マネキン・ポリゴン・ゆるキャラ・欧米カートゥーン・劇画に見えない）。
2. **顔が美しい**：目の大きさと高さ、左右の対称、目と目の間隔、顎のライン、3/4の奥の頬の処理、横顔の鼻と口。可愛すぎない（先輩は大人びた美人、彼は涼しげな少年）。
3. 先輩と彼が**見分けられる**（髪型・目つき・体格・色）。
4. **表情が芝居として読める**：泣き（涙が溜まる→こぼれる）、叫び、微笑み、空虚な目（ハイライトが消える）、驚き、決意。
5. **線がきれい**：ギザギザ・太さのムラ・閉じていない線・はみ出し・二重線がない。
6. **塗りが破綻しない**：影のはみ出し、抜け、パーツの前後関係の間違い（髪が顔の前後を誤る等）がない。
7. どの照明（day / window / sunset / night / storm / stage / room_gray / lamp …）でも成立し、暗いシーンでも形が読める。
8. 小さく描いても（頭の高さ40〜80px）崩れず、大きく描いても（頭の高さ400〜600px）粗が出ない。
