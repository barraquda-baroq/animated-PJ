# 美術・作画スタイルガイド（『キミの右手のアイロニー』PV）

## 全体トーン
- 劇場アニメの背景美術（新海誠作品・京都アニメーション作品のような、光と空気の描写が美しい背景）＋「影絵」的な人物表現。
- 人物は顔の演技を見せない。後ろ姿、逆光シルエット、髪や影で顔が隠れた構図、手元のアップで語る。
- 光が主役：窓から差す光芒、逆光のリムライト、ブルーム、空気中の塵、レンズフレア。暗い場面でも必ずどこかに光源がある。
- 最終画面にはエンジン側でブルーム・粒子ノイズ（フィルムグレイン）・周辺減光が乗る。描画側では過度に暗くしない（最暗部でも #0b0f1a 程度）。

## キャラクター
- 先輩（ヒロイン、高3、ピアニスト）：長い黒髪（腰近くまで、まっすぐ、風で大きくなびくと美しい）、細身、制服（紺のブレザー or 白ブラウス＋三年生の赤いリボン、紺のプリーツスカート）。コンクールでは濃紺のドレス＋カーディガン、低いヒール。夏はつばの広い白い帽子と白いワンピース。事故後は右腕にギプス／アームスリング、右肩から指先に縫合痕。
- 主人公（高2、ギタリスト）：少し長めの無造作な黒髪、細身で背が高め、制服の白シャツ（夏）／学ラン風ではなくブレザー、夜はくたびれた革ジャン。左手の指先に弦の硬いタコ。物語中盤以降、左手親指の付け根に傷痕。愛用は塗装の剥げた白いストラトキャスター（母の形見）と傷だらけのアコースティックギター。
- シルエットで二人が見分けられること：彼女＝長い髪のライン、彼＝ギターの形と肩幅。

## 手の作画（最重要モチーフ）
- 先輩の右手：細く長い指、ただしピアニストらしく関節はしっかり、爪は短い（本人は「可愛くない」と気にしている）。
- 主人公の左手：骨ばっていて指先に弦のタコ（指先のやや平たい硬い皮膚、薄い茶色の線で表現）。
- 塗り：アニメのセル塗り（ベース＋1影＋ハイライト）。ベース肌色 #f3d3bf 前後、1影 #d9a38e 前後、ハイライト #fff1e6、線は細い暖色の茶 #6b3f33（1.2〜2px、画面スケール1080p基準）。逆光シーンでは暗い肌色＋縁の明るいリムライト。
- 解剖学的な破綻（指の数、関節の向き、長さの比率）は絶対に避ける。指の長さ比：中指＞薬指≧人差し指＞小指、親指は手首寄りから生える。

## 色彩設計（シーン別の基調）
- 春の音楽室：温かい午後の光。#fff3dc の光、#f6e6cf の壁、#c9a77d の木の床、窓の外は #9cc8ee の空。
- 中庭の青空：#5d9be0〜#bfe0f8、雲は白〜#a9bde0 の影。
- 雨の音楽室：青灰色 #4a5568〜#8a97ab、窓に流れる雨、カーテンの白が沈む。
- 文化祭の体育館：暗い室内 #141420、スポットライト（琥珀 #ffbf6b、マゼンタ #ff5fa8、シアン #5fd7ff）。
- 夏の海：#2f7fd8 の海、白い大橋、入道雲、強い日差し。
- コンクール：真っ白な世界（#f8f8f6）に浮かぶ黒いピアノ、紺のドレス #1c2541、スポットライト。
- 夜の臨海公園：#0e1530〜#1d2b55、対岸の夜景のボケ（琥珀・白・薄桃）。
- 病室：冷たい白 #eef3f5、薄い水色の影、秋の高い青空、窓の外の白い橋。
- 嵐の橋：#070b16〜#1a2338、雷光で一瞬白飛び、雨の筋。
- 沈黙の日々：彩度を落としたベージュ灰 #8d877f、曇り。
- 音が戻る夏：明るい白金色の光 #fff6dd、蝉の季節の濃い青空。
- タイトル：白〜淡い金。

## 実装ルール
- Canvas 2D API のみ。関数は PV.lib.xxx(ctx, opts) の形で、位置・スケール・時間 t を引数で受け、決定論的（Math.random禁止、PV.rng/PV.noise2を使う）。
- 静的な部分は PV.cached(key, w, h, paintFn) でキャッシュし、1フレームの描画は重くても 40ms 以内を目安に。
- ctx の状態は save()/restore() で必ず元に戻す。
