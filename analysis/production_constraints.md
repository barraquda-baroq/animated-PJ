# 制作上の技術的制約（全スタッフ必読）

この3分PVは、以下の環境で「実際に」制作する。絵コンテ・脚本はこの制約内で最大の感動を出すこと。

## 映像
- 生成AI画像は使えない。すべてコードで描く（ヘッドレスChromium上の Canvas2D / WebGL / SVG を 1920x1080・24fps でフレーム書き出し）。
- 得意：背景美術（空のグラデーション、雲、光芒、逆光、レンズフレア、粒子、雨、雷、雪、花びら、海のきらめき、夜景のボケ、白い大橋のシルエット）、室内（窓・カーテン・グランドピアノ・鍵盤のクローズアップ、譜面、音符の粒子）、シルエット人物（後ろ姿、逆光、長い黒髪がなびく、膝をつくギタリスト、並んで座る二人、抱き合う二人）、手のクローズアップ（鍵盤の上の右手、弦を押さえる左手、指先の弦の傷、ギプス、指を絡める二つの手）、小物（弁当、タコさんウインナー、パックジュース、有線イヤホン、スマホ画面、ハンドクリーム、耳栓、ネックレス、リンゴ、傘、白いストラトキャスター、アンプの赤いランプ、心電図モニター）、タイポグラフィ（明朝体の縦書きモノローグ、キャッチコピー、タイトルロゴ）、カメラワーク（パン、ズーム、パララックス、ピント送り風のぼかし）、トランジション（白飛び、暗転、フラッシュ、ディゾルブ）、色調設計。
- 苦手（避ける）：顔の細かい演技、口パク、複雑な全身アニメーション、群衆の個別演技。人物は「後ろ姿・逆光シルエット・顔が髪や影で隠れた構図・手元・目元の極端なアップ（少数）」で見せる。
- 1カットは概ね2〜8秒。3分で30〜45カット程度。

## 音声
- キャラクターは日本語音声合成（VOICEVOX系の音声）で発話する。感情表現は話速・抑揚・音高・間で調整可能だが、叫びや嗚咽の生々しさには限界がある。
  → 台詞は短く、強く、意味が一聴で伝わるものを選ぶ。長台詞は避ける（1台詞は概ね25文字以内、最大でも40文字）。
  → 「……」の間（ま）は無音として演出できる。
- 台詞は原作本文から一字一句引用するのが原則（改変は最小限の省略のみ）。
- 字幕（画面下の台詞テキスト）を出せる。モノローグは縦書きテロップで出せる。

## 音楽・効果音
- 劇伴はオリジナル作曲（MIDIで作曲し、ピアノ・弦楽・アコースティックギター・エレキギター・ベース・ドラム等のサンプル音源で演奏）。
- パブリックドメインのクラシック（ショパン〈別れの曲〉〈木枯らし〉、リスト〈雪あらし〉、バッハ〈G線上のアリア〉、ベートーヴェン〈ワルトシュタイン〉、シューマン〈トロイメライ〉、ドヴォルザーク〈母の教えてくれた歌〉等）は引用可。ジャニス、ジミヘン、ジョージ・ウィンストン、ストラヴィンスキー等の著作権曲は使わない。
- 効果音は合成で作る（雨、雷、風、波、汽笛、蝉、チャイム、拍手、ブーイングのざわめき、弦が切れる音、心電図モニター音、鼓動、車のヘッドライト／ブレーキ音、ページめくり、ハムノイズ、アンプのノイズ等）。
- 尺は厳密に180秒。
